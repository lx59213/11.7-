# 现成的技能和队员

GitHub 上口碑好的开源技能和岗位说明书，课前挑好放在这里，网络不通也能用。每个都保留原作者和许可证。

## 什么时候用

- 自己做的技能、智能体这一轮比输了，或者不想再一句句改了：从这里借一个最贴的当底子，把自己说过的做法加进去，再比一次。
- 编队时缺队员：从「队员」里挑，照它的岗位说明书干活。
- 课后想多装几个：技能复制到 WorkBuddy 的 ~/.workbuddy/skills/ 或 Codex 的 ~/.codex/skills/；队员整篇贴给 AI，说「照这份岗位说明书干活」。

## 技能（23 个，在 技能/ 下）

写和改
- Humanizer-zh：把 AI 写的改得像人写的，去掉套话和排比。写什么都用得上。（歸藏，MIT）
- baoyu-translate：翻译，分快译和精译，精译先读懂再译再润色。（宝玉，MIT）
- baoyu-format-markdown：把一大段乱文字排成有标题、重点、列表的文章。（宝玉，MIT）
- internal-comms：写周报、进展汇报、内部通知、事故通报。（Anthropic，Apache-2.0）
- doc-coauthoring：和 AI 一起写方案、制度、提案：先问清楚，再一节节写，最后找没看过的人读一遍。（Anthropic，Apache-2.0）
- content-research-writer：查资料写文章，每个说法带出处。（Composio，Apache-2.0）
- brainstorming：动手前先问清楚要做成什么，给两三个方向再定。（obra/superpowers，MIT）
- tailored-resume-generator：照岗位要求改简历；招人的反过来用它把岗位要求写清楚。（Composio，Apache-2.0）

出文件（要电脑上有 Python，AI 会自己装需要的库）
- docx：出和改 Word，带格式、表格、修订痕迹。（Anthropic，Apache-2.0）
- xlsx：出和改 Excel，带公式和图表。（Anthropic，Apache-2.0）
- pptx：出和改 PPT。（Anthropic，Apache-2.0）
- pdf：读、拆、合 PDF，填 PDF 表单。（Anthropic，Apache-2.0）
- frontend-design：做好看的网页、活动页、产品页。（Anthropic，Apache-2.0）

出图（要软件能出图：WorkBuddy、Codex 都能）
- baoyu-infographic：把一段内容做成信息图，21 种版式。（宝玉，MIT）
- baoyu-xhs-images：一组 1 到 10 张小红书图卡。（宝玉，MIT）
- baoyu-slide-deck：把一篇内容做成一套图片版幻灯片。（宝玉，MIT）

做网页幻灯片和动效片（纯 HTML，一个文件，学员电脑不用装任何东西。只放了说明文字，没放脚本）
- huashu-design：先出三个方向让人选，再做网页、幻灯片、动效片，带评审清单。（花叔，MIT）
- frontend-slides：做动效丰富的网页幻灯片，一个 HTML 文件，带风格样例和动效写法。（Zara Zhang，MIT）
- baoyu-diagram：流程图、结构图，不用出图工具。（宝玉，MIT）

调研和整理
- competitive-ads-extractor：拆竞品广告：卖点、话术、素材套路。要联网。（Composio，Apache-2.0）
- lead-research-assistant：找潜在客户，写清为什么找他。要联网。（Composio，Apache-2.0）
- meeting-insights-analyzer：看会议记录：决定了什么、谁说得多、哪些话题被绕开了。（Composio，Apache-2.0）
- invoice-organizer：整理发票和收据，改名归档，出一张汇总表。（Composio，Apache-2.0）
- file-organizer：整理乱文件夹，找出重复文件。（Composio，Apache-2.0）

软件自带的（不在这个文件夹里）
- 出视频：WorkBuddy 自带视频生成（可灵、Seedance、MiniMax 等），文字或图片生成 4 到 15 秒视频。对 WorkBuddy 说「生成一段视频」就会用上。
- 出图：WorkBuddy、Codex 都能直接出图。

## 队员（55 个岗位说明书，在 队员/ 下，按部门分）

来自 agency-agents 中文版（GitHub：jnMetaCode/agency-agents-zh，MIT 许可证）。每篇写了这个岗位是谁、管什么、不碰什么、交什么。拿来当智能体的岗位说明书第 1 版，或者编队时当一个队员。用之前加三样：查哪个知识库、交给谁、什么事停下问人。

- 老板和高管：首席执行官、首席运营官、首席营销官、首席财务官、幕僚长、商业战略家
- 宣传和内容：视频提示词工程师、视觉叙事师、品牌守护者、图像提示词工程师、广告创意策略师、抖音策略师、小红书专家、微信视频号运营策略师、微信公众号管理、短视频剪辑指导师、内容创作者、TikTok策略师、PR与传播经理
- 电商和销售：跨境电商运营专家、中国电商运营专家、直播电商主播教练、私域流量运营师、邮件营销策略师、客户拓展策略师、销售教练、赢单策略师、投标策略师、定价分析师
- 客服和售后：客服响应者、客户成功经理、零售退货专家、反馈分析师
- 财务和法务：财务分析师、簿记与财务总监、发票管理专家、税务策略师、合同审查专家、制度文件撰写专家、企业风险评估师
- 人事和培训：招聘专家、绩效管理专家、HR入职管理专家、企业培训课程设计师
- 采购和供应链：供应链采购策略师、供应商评估专家、库存预测专家、物流路线优化师
- 调研和管理：趋势研究员、产品经理、新闻情报官、数据分析师、高管摘要师、会议纪要专家、运营经理

## 清单里没有合适的

网络通的话，可以去 GitHub 搜：挑星多、写明许可证、最近还有人更新的。只拿 SKILL.md 和它说明里要的文件，看不懂的脚本不运行。
