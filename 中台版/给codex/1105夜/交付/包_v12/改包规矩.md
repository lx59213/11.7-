# 改包规矩

技能包、智能体包，谁改都照这一页。我们教学员改技能是“一次改一句，盲比赢了才留”，自己的包也这样改。

## 每次改

1. **先写考题再改。** 发现一个毛病，先在 考卷.md 加一道题：学员怎么说、AI 该怎么做、看哪个文件算过。拿旧版跑这道题，确认它真挂了，再改。
2. **一次只改一处。** 先找包里有没有已经管这件事的那句，改那句，不另加一条。同一件事两处说法不同，AI 就会挑一处照做。
3. **篇幅不涨。** 加一句就删一句。出包时 check_包.py 会比篇幅，多出 2% 就不出包；确实要涨，带 --接受篇幅 跑一次，提交说明写为什么。
4. **出包自动检查。** build_2_技能.py、build_3_智能体.py 会先跑 check_包.py，查四处说的是不是一回事：包、操作手册、课件动手屏和口播、看板网页。比的是步数、分钟、最多问几句，引用的文件在不在，有没有旧叫法和虚构案例。有一条不过就不出包。
5. **跑考卷。** 改了规矩（不是只改字），跑 考卷.md 里和这处有关的题，再加三道必跑题。旧版过的题，新版挂一道就退回。
6. **一处一个提交。** 提交说明写：改了哪句，因为哪道题。包源文件在 git 里，改坏了能看出改了哪句、能退回去。

## 不算毛病的

- 学员没答、答偏，AI 照实写了一般、不如不用或缺什么：这是包在说实话，不改。
- 只在一个软件里出现、换个软件就好的：先记进考卷，标是哪个软件，不急着改包。
