# 工作台怎么用（给参谋看，不给学员看）

下面"工作台"指 python 〈4_人机编队 的路径〉/工作台/工作台.py，"队伍"指 队伍/〈队名〉（建在当前工作区，和 知识库/ 同一层）。命令一览：工作台 -h。工作台还会更新，命令以 -h 和 下一步 打出来的为准。

## 一、总规矩

- 每做完一件跑 `工作台 下一步 队伍`，照它打出来的命令跑，〖〗里换成实际的字。
- 看板没开：`工作台 开 队伍 --打开` 起在后台（Mac：nohup … > 队伍/.工作台.log 2>&1 &；Windows：Start-Process 隐藏窗口），把 队伍/.看板网址 里的网址告诉他一次。
- "等"类命令最多等 4 分钟，没等到就停下，他发来任何话先跑 下一步。
- 出视频要半分钟到两分钟，等命令自己结束。
- 工作台一跑就卡住或报锁：前面加 `env -u PYTHONPATH` 再跑。curl 发给看板的请求加 `--noproxy '*'`（他开着代理时，不加连不上本机）。

## 二、三处在看板上点：你跑什么、等什么

主路：先把要他点的卡放上看板（下面"你先跑"那列，会等人的命令一律加 `--不等`），再在对话里摆例子、问一句，说"去看板右边点一下"，说完再跑等待命令。顺序不能反：先等再说，他不知道要去点。等待命令最多等 4 分钟；没等到就停下，他回"点好了"或任何话，你再跑一次同一条等待命令。等到了，下一条消息第一句先说变了什么、为什么。

| 这一处 | 你先跑 | 他在看板上 | 你等 | 等到以后 |
|---|---|---|---|---|
| 开工单（不问他） | `工作台 填表 队伍 --公司 … --卖什么 … --卖给谁 … --发在哪 … --最怕说错 "知识库里写着的忌讳"`，再 POST 〈网址〉api/开工单，正文 {"公司","卖什么","卖给谁","发在哪","最怕说错"} | 不用点 | — | 跑 下一步 |
| 定规矩：最怕出什么错 | 在对话里问，他在对话里答。`工作台 记学员答 队伍 --时刻 开工前定规矩 --问 "最怕出什么错" --答 "原话"`；`工作台 加红线 队伍 --一句 "照原话写的一条"` | 不用点 | — | 接着提建议 |
| 定规矩：改不改这一处 | `工作台 提改队 队伍 --动作 加 --名 〈候选队员〉 --多等 "每轮多等约 2 分钟" --例子 "…" --问 "…"`（或 `--动作 加一句 --名 〈队员〉 --一句 "规矩"`） | 点"加"或"不加"，点完开工 | `工作台 等改队 队伍` | 返回"改了"什么、现在的队员，照它回一句 |
| 挑方向 | 下一步给的 `工作台 请示 队伍 --标 方向 …` 加 `--不等`，记下编号 | 三个里点一个 | `工作台 等拍板 队伍 〈编号〉` | 返回拍板的选项，回一句这个方向让谁多做什么 |
| 挑成品 | 下一步给的 `工作台 盲比 队伍 --说明 … --改后 … --改前 …` 加 `--不等`，记下编号（命令名不对他说） | 点甲、乙或差不多，写一句哪里不行 | `工作台 等盲挑 队伍 〈编号〉` | 返回"选""挑中的是""我说"。揭晓；"我说"空着就在对话里问一句 |
| 成品能不能用 | 下一步让你开"发不发"请示时加 `--不等`，用他挑成品时写的话直接 `工作台 拍板 队伍 〈编号〉 --拍板 "能用"或"不能用，哪里不行写一句" --意见 "他写的哪里不行"` | 不用再点 | — | — |

后备：他没去点，在对话里直接答了，你替他交，不用说他：

| 他在对话里说的 | 你跑 |
|---|---|
| 加 / 不加 | 加：`工作台 改队 队伍 --动作 加 --名 〈候选〉`（加一句：`--动作 加一句 --名 〈队员〉 --一句 "…"`），再 `工作台 改队 队伍 --动作 开工`；不加：直接 `--动作 开工` |
| 删、换一个队员（他自己提的） | `工作台 改队 队伍 --动作 删 --名 〈队员〉`；换：`--动作 换 --名 〈队员〉 --照着 〈岗位说明书路径〉`。写、挑错、做这三类删不了，工作台会说为什么，照它的话告诉他 |
| 挑方向 1、2、3 | `工作台 拍板 队伍 〈编号〉 --拍板 "他挑的那个选项原文"` |
| 挑成品甲、乙 | `工作台 挑 队伍 〈编号〉 --选 甲|乙|差不多 --我说 "哪里不行，原话"`，再 `工作台 等盲挑 队伍 〈编号〉` 拿到"挑中的是" |

不在三处里的：

| 看板要他做的 | 你跑 |
|---|---|
| 脚本里挑错 | 他不想挑：POST 〈网址〉api/人挑 {"id": 编号, "行": [], "意见": "不挑"} |
| 还要再来一轮吗（工作台第二轮后会问） | 拍 "先到这里，进收尾"。第三轮从菜单换一支队 |
| 排每周几、要不要先给你看 | 请示加 `--不等`，对话里说一句"去看板右边点一下"，再跑 `工作台 等拍板 队伍 〈编号〉` |

看板网址记作 〈网址〉（队伍/.看板网址 里那一行）。POST 用 curl 或 python 发 JSON 都行。揭晓那一句要的证据：`工作台 看 队伍` 打出来的交接、退回、挑错拦下、照他那条规矩拦下几处。

## 三、课上六步各自停在哪

工作台自己按第 6 到 9 步算，课上学员看到的是第 1 到 6 步，两套编号不一一对应。工作台说"第 N 步做完了，写结束三行，停"时，没到下表的终点就跑 `工作台 进下一步 队伍` 接着做，不写结束三行。没到终点他就发来下一步，先把这一步做到终点再接着做。

| 课上 | 做什么 | 停在哪 |
|---|---|---|
| 第 1 步：配一支队 | 问一件事、三句话、`开工 队伍/〈队名〉 --从 〈队名〉`、`开 --打开` 起看板、填开工单替他交上、说每个队员补哪一句 | 配好队、看板打开 |
| 第 2 步：定规矩，开跑 | 问最怕出什么错、记学员答、加红线、提改队 → 等改队；一个 AI 直接做一份；进下一步；请示方向 → 等拍板；队伍做 | 队伍交出成品、还没跑 盲比 摆出两份 |
| 第 3 步：挑成品 | 盲比 → 等盲挑；揭晓；拍板"发不发"用他写的话 | 揭晓完、他说了哪里不行（工作台说第 7 步做完了） |
| 第 4 步：改一处，跑第二轮 | 进下一步；先问他觉得是哪个队员的问题，再拿 `看 队伍` 的记录对；改一处；再跑；挑成品（对第一轮）；揭晓、说这一处有没有用 | 揭晓完，工作台问再来一轮时拍"先到这里"、说第 8 步做完了 |
| 第 5 步：换一支队 | 从菜单推荐另一支（跟他家生意最搭的），他点头就 `开工 队伍/〈队名〉 --从 〈队名〉`，从开工单到揭晓再走一遍；他自己带，你少说。课上不用自配 | 新队揭晓完 |
| 第 6 步：收尾 | 两支队都跑 进下一步 到第 9 步、跑 收尾、排班、放手；写 队伍花名册.md 和 业务地图.md；请他说一句回去先把哪件事交给队伍 | 写完结束三行，最后一行"这支队做完了" |

每步停下时写三行，〖〗以外不改。N 写课上的第 1 到 6 步，不写工作台的编号；数字照 `工作台 看 队伍` 的计数写：

```
【第 N 步结束】产出：〖这一步做成了什么〗
看：队伍看板。交接〖几〗次，退回〖几〗次，你说了〖几〗句。
下一步：听讲师讲完，复制下一步那段发过来。
```

## 四、挑一件事：选项对哪支队

先读 队伍菜单/队伍菜单.md，再跑 `工作台 菜单` 看七支队的"适合"和"问"。选项写成他家的事，不写队名：

| 他家的事（举例） | 队 |
|---|---|
| 给新品写标题五点、做卖点图 | 上新队 |
| 回客户来信、退货投诉 | 售后队 |
| 每周给老板报数、讲涨跌原因 | 周报队 |
| 做一条产品或公司的短视频 | 宣传片队（文件夹 宣传片队_v2，对他只说宣传片队） |
| 写招聘文案、介绍公司 | 招聘队 |
| 给客户出方案、报价对比 | 方案队 |
| 带新人学一件事 | 培训队 |

配好告诉他每个队员补三句里哪一句：队伍.json 里"类"是查、写、做的补第 1 句（一个岗位）；挑错补第 2 句（一道把关）；想补第 3 句（让他定方向）。专门翻差评、查规矩、为拦一种错加的，算补第 2 句。

都对不上：课上挑最像的一支现成的队跑。回去以后他说"再配一支队"时，才从 现成的技能和队员/队员/ 里照那件事配一支，骨架是查、写、挑错、做（需要时加一个想，查最多 3 个），写成 队伍/〈队名〉/队伍.json（格式照 队伍菜单/培训队/队伍.json），跑 `工作台 开工 队伍/〈队名〉 --从 自配`。

已经开过工的（换了对话、电脑重启过）：不重来，跑 下一步接着做，告诉他做到第几轮了。

## 五、知识库里写什么

- 队伍档案：知识库/wiki/智能体/〈队名〉.md，页头照库里别的页写（类型: 队伍、状态、更新）。每个队员一行（照着谁、第几版）、他定的规矩、每一轮的结果、改过的那一处。wiki/index.md 加一行。
- 收尾命令写出的 队伍/〈队名〉/我这节课定的.md，复制成 知识库/wiki/智能体/〈队名〉_我这节课定的.md，index 加一行。
- 队伍花名册：知识库/wiki/智能体/队伍花名册.md，一支队一节：

```
## 上新队（2026-11-08 配）
- 做什么：给新品出 5 张卖点图卡加标题五点
- 队员：卖点方向 → 查差评的（第 1 轮加的）→ 卖点调研 → 写详情 → 挑错 → 出图
- 他定的规矩：尺寸只写知识库规格页的数，不写"约"
- 改动记录：
  - 11-08 第 1 轮后：加"查差评的"，因为他说最怕尺寸写错。第 2 轮他挑了改过的这份。
- 每周：周一上午跑一次，先给他看
```

- 业务地图：知识库/wiki/业务地图.md（回去以后"梳理我家业务"写的），一件事一行：事、谁做、每周几次、一次多久、错一次亏多少、三句各答什么（如"是是不"）、该怎么交（组队、一个智能体加定时、写一个技能）、配队了没有。
- 昨天的看板 知识库/看板/看板数据.js 有的话，每步结束照 知识库/_参考/看板网页/怎么做看板.md 第 3 节只改要改的几行：数字里加"队"、最近加一句、更新改成现在、"成果"加一条。没有就跳过。
