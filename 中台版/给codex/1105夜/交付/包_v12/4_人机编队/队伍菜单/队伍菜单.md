# 队伍菜单

前四支课上能直接开工，岗位说明书都写好了，在各自文件夹里。后面几支回去照着组。每支队都有一个只挑不改的挑错队员，人只在「人拍板」那里出手。
「照着」是 现成的技能和队员/队员/ 里的岗位说明书，「用」是 现成的技能和队员/技能/ 里的技能。

## 课上能开工的四支

### 宣传片队
- 做什么：给公司或产品做一条 8 到 15 秒的竖屏视频
- 队员：策划 → 编剧分镜 → 挑错 → 出片
- 人拍板：挑选题；成片发不发
- 适合：想做短视频的。出片要等半分钟到两分钟，视频出不来就改交分镜图卡

### 商品主图队
- 做什么：给一个产品做一套主图和卖点图卡（5 张），加标题和五点
- 队员：卖点策划 → 文案 → 挑错 → 出图
- 人拍板：挑主打方向；这套图今天能不能上架
- 适合：卖实物、知识库里有产品和卖点的

### 社媒图文队
- 做什么：一组图卡（6 张）加一篇笔记，发小红书、公众号或朋友圈
- 队员：选题 → 写笔记 → 挑错 → 出图
- 人拍板：挑选题；发不发
- 适合：做内容的，库里有公司和产品介绍就够

### 客户回信队
- 做什么：三封客户来信的回信定稿，加一份内部备注
- 队员：分拣 → 起草 → 挑错 → 定稿
- 人拍板：先回哪封；降价、赔钱、对外承诺的信能不能发
- 适合：不想碰图和视频、知识库里有价格和售后规矩的

## 回去可以照着组

「照队伍菜单组一支〖队名〗」，AI 照上面四支的样子写分工表和岗位说明书。

- 竞品周报队：每周一份竞品动向，一页纸。收集（照着新闻情报官，用 competitive-ads-extractor）→ 分析（照着商业战略家）→ 写周报（照着高管摘要师，用 internal-comms）→ 挑错（查出处、是不是这周的）。人拍板：哪条要跟进。
- 招聘初筛队：简历先筛一遍，约面试。写岗位要求（照着招聘专家）→ 筛简历（用 tailored-resume-generator）→ 写约面消息 → 挑错（查有没有按年龄、性别筛）。人拍板：约谁来面。
- 会议跟进队：开完会出纪要、分任务、到期提醒。整理（照着会议纪要专家，用 meeting-insights-analyzer）→ 分任务（照着幕僚长）→ 挑错（查每件事有没有人、有没有日期）。人拍板：纪要发不发、任务分给谁。
- 报表分析队：每周数据出一份带图的分析。读数（照着数据分析师，用 xlsx）→ 写结论（照着财务分析师）→ 出 PPT（用 pptx）→ 挑错（查每个数和原表对不对）。人拍板：结论对不对、发给谁。
