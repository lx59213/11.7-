# 练习示例：给这款新品再做一张独立站首页横幅图（示例）

画面清单、出不了图时写给设计同事的出图说明、Agent 列的差别、打回的话，都在下面。出图后，自己的图和打样实拍、出图规范一起交给 Agent 核。没出成图的，第 3 步拿 机身有字的主图.jpg 练。

（画面清单，示例）
用在哪：猫狗家独立站首页横幅图，横版 1920×600
1. 左边三分之一留白，之后在设计软件里加标题和按钮
2. 右边：饮水机放在客厅木地板上，一只小狗侧面在喝水，电源线收在机身背后
3. 早上的自然光，机身雾青、盘面月白，釉面哑光
标题和按钮（设计软件里加，用品牌色澜青）：New: 3L Ceramic Fountain（新品：3 升陶瓷饮水机） / Shop now（去看看）
不许：照出图规范六条，机身上不加字和标志，猫狗不碰电源线

（出不了图的，写成出图说明，给设计同事，示例）
用在哪：独立站首页横幅图
尺寸：横版 1920×600
画面：右边饮水机放在客厅木地板上，一只小狗侧面在喝水，电源线收在机身背后；早上的自然光
留白：左边三分之一留出放标题和按钮
文字（设计软件里加）：New: 3L Ceramic Fountain（新品：3 升陶瓷饮水机） / Shop now（去看看）
不许：机身上有字、有标志；颜色不照色卡；釉面像塑料；小狗碰到电源线

（Agent 列出出的图和打样实拍、出图规范的差别，示例）
1. 机身侧面多了一行小字：违反规范，重出，第 1 条：机身上不许 AI 加字、加标志
2. 小狗的前爪踩在电源线上：违反规范，重出，第 6 条：猫狗不能碰到电源线
3. 木地板比画面清单里写的颜色深：没违反，规范没写地板颜色，可以留

（打回的话，示例）
第 1、2 条违反规范，重出：机身上不要有字，也不要标志；电源线收在机身背后，小狗碰不到。第 3 条不用改。
重出后再让 Agent 列一次差别，违反规范的都改掉才算过。
