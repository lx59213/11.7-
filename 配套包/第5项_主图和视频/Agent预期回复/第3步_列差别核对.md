# 第 3 步：把打样实拍、出的主图和出图规范交给 Agent，列出差别，自己核哪条违反规范（示例）

差别：
1. 机身正面多了一个标志和一行认不出的字
2. 背景从打样时的灰布换成了纯白
3. 釉面反光又硬又亮，看着像塑料
4. 盘面里的水多了几道波纹

对着出图规范核：
1. 违反规范，重出：第 1 条：机身上不许 AI 加字、加标志
2. 没违反：第 5 条：主图要的就是纯白底
3. 违反规范，重出：第 3 条：釉面要哑光，不能像塑料
4. 没违反：规范没写这一条，可以留

重出的话：第 1、3 条违反规范，重出主图：机身上不要有字，也不要标志；釉面照打样实拍，哑光，不要塑料那种亮反光。第 2、4 条不用改。标志之后用标志原图叠上去。
