# 练习：滤芯随机送三片，还是单卖？（猫狗家 3 升陶瓷款智能饮水机）

联网用，让 Agent 上网查。慢的、查不到的，直接看“Agent预期回复”里的三份示例资料卡，对着做后两步。

## 1　先贴给 Agent

要定的事：猫狗家的 3 升陶瓷款智能饮水机，滤芯要不要随机送三片，还是单卖？
拆成三问：请先把这件事拆成三个问题，每个问题要能靠查到的资料回答
读哪里：上网搜；出处要能点开
每问查：两个来源，各写一句；每条带出处：来源的名字，加我能点开的网址
不许：编链接，编数字；查不到、打不开的写“没查到”

## 2　点开每条出处以后，贴给 Agent

我点开了六条出处，请照我说的改资料卡。每条写：标签（能用 / 说大了 / 不能用）和一句原因。
第 1 问 A：
第 1 问 B：
第 2 问 A：
第 2 问 B：
第 3 问 A：
第 3 问 B：
标成“说大了”的，改成原网页上的说法；标成“不能用”的，原来那句话不要留着，改写成“没查到”。

## 3　有一问两个来源说法不一样，点开两份看完，贴给 Agent

资料卡里有一问的两个来源说法不一样。我点开了两份，看了样本量、日期、谁发的。请在那一问下面加两行：
信哪个：（A / B）
为什么：（样本量、日期、谁发的，各写一句）
没信的那一条，标成“只当线索”。

---
看三样：样本量多大、日期新不新、谁发的（和这件事有没有利害关系）。
标签：能用 = 页面上就是这句；说大了 = 比原页夸大，改回原话；不能用 = 打不开或找不到，改写成“没查到”。
