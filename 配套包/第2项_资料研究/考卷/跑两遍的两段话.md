# 第 2 项：同一件事，两种做法各跑一遍

同一个 Agent，两种做法各新开对话，各跑三遍。两种做法拖进去的文件一样：“材料”文件夹（10 个文件）和“考卷/题目.md”。“标准答案_别交给Agent.md”不拖进去。

## 只说一句

拖进文件，只说这一句：

帮我查查 3 升陶瓷款饮水机该不该上，同事交来的汇总在题目.md 里，材料都在附件。

## 用课上的做法（照第 2 项）

拖进文件，先贴这一段（第 2 项的研究说明，换成这份汇总）：

要定的事：猫狗家要不要上一款 3 升陶瓷款智能饮水机
拆成三问：先把这件事拆成三个问题，把题目.md 里的 24 句按三问归好
读哪里：只读“材料”文件夹，不上网搜
每句做：点开它写的出处，对原页上的话，贴一个标签，再写一句原因。能用 = 页面上就是这句；说大了 = 页上有这条，但说法或数被放大了，改回原页的说法；不能用 = 打不开或找不到，改写成“没查到”
不许：编链接，编数字；材料里没有的写“没查到”

它交回以后，再贴这一段（第 2 项第 3 步）：

题目.md 第 25、26 问，都是两个来源说法不一样。请各看样本量、日期、谁发的，写信哪个、为什么；没信的那一句标“只当线索”。

- 从发出到能用：从发出第一句话算起，到手里有一份 26 条都改对了、能拿去开会的汇总为止，自己改的时间也算。
- 对了几条：Agent 交回的结果（人改之前），照“标准答案_别交给Agent.md”最后的判法数。
- 人改了几处：为了改到和标准答案一致，自己动手改或让 Agent 重改的句子，一句算一处。
