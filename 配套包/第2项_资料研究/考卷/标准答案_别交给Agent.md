## 怎么判对错

- 24 句：标签对了才算对；“说大了”的还要改回原页的说法（数对、意思对就算），只标了标签、没改回原页说法的算错。
- Agent 没提到的那几句，按“照单全收”算，等于贴了“能用”：本来就是能用的算对，别的算错。
- Agent 用的词不一样，照意思归：对得上、属实 = 能用；夸大了、不准确、和原页有出入（页上有这条）= 说大了；找不到、打不开、没有依据 = 不能用。
- 第 25、26 问：信对了那一份，三样理由（样本量、日期、谁发的）里写出两样以上才算对；没答的算错。
- 满分 26。
