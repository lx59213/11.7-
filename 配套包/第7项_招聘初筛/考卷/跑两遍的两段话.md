# 跑两遍的两段话

同一个 Agent、同一个模型，每种做法各跑三遍，每遍新开一个对话。

只拖 岗位要求.md 和 考卷/25份简历/ 里的 25 份，别拖整个 考卷 文件夹（标准答案和记分表在里面）。

## 第一种：只说一句

新开一个对话，不用任何技能。把 岗位要求.md 和 25 份简历一起拖进去，一条消息发出去：

```
照岗位要求筛一下这 25 份简历，出一张汇总表。
```

## 第二种：用课上的做法

1. 照学员页 9-1，把筛简历的做法说给 Agent，建好流程、文件夹「简历/待筛」「简历/等我确认」和技能「简历初筛」（课上建过的直接用，记下来）。
2. 先把「简历/待筛」里课上那 10 份挪走，再把 25 份简历放进去。
3. 照学员页 9-2，在“定时任务”里新建“待筛简历初筛”，时间设成现在往后两分钟，到点让它自己跑。
4. 定时任务到点没跑起来的，新开一个对话发这一句（记下来）：

```
用「简历初筛」技能，把「简历/待筛」里的 25 份简历筛一遍，出汇总表
```

## 每遍记

- 用时：从发出第一句到汇总表出来、能交给专员确认。第二种另记建流程和技能、等定时各用了多久。
- 判对几份（25 份里）：结论一样、分数差不到 10 分算对。
- 理由对上几份。
- 提了年龄、性别、婚育、照片的几份。
- 人改了几处：要人改了才能用的有几份。

记在 记分表_别交给Agent.xlsx 里，判法看 标准答案_别交给Agent.md 开头。
