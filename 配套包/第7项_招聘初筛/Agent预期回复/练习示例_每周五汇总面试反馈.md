# 每周五汇总面试反馈（示例，我们写的）

## 说给 Agent 的流程

1. 面试官群聊记录放进「反馈/本周」
2. 对照汇总表，更新每个人的状态和反馈
3. 一面通过的人写成名单草稿，放进“等我确认”　←　人确认
4. 我确认以后，名单才发给用人部门

文件夹：反馈/本周、反馈/等我确认。技能：周五反馈汇总。
