# 练习：每周五汇总面试反馈，给用人部门一份约下一轮的名单

材料：面试官反馈群.txt、汇总表_上周在面.xlsx（都在这个文件夹里）。

## 第一段：说给 Agent，建成流程

我是招聘专员，每周五要把面试官在群里的反馈汇总进汇总表，再给用人部门发一份约下一轮的名单。帮我建一条流程：
1 面试官反馈群的聊天记录放进「反馈/本周」，就对照汇总表_上周在面.xlsx，找到每个人，更新状态和面试反馈，没提到的人不动
2 一面通过的人，写进约下一轮的名单草稿，每人一行，写明面试官怎么说
3 名单草稿放进“等我确认”，我确认之前不要发给用人部门；反馈里提到薪资超预算的，只标一句，不要替我回候选人
4 我确认以后，名单才发给用人部门；汇总表每人一行
画成流程图，再把文件夹和技能建好，技能叫「周五反馈汇总」。

## 第二段：设成定时（照第 2 步）

- 名称：周五反馈汇总
- 提示词：用「周五反馈汇总」技能，把「反馈/本周」里的面试官群聊记录，对照汇总表_上周在面.xlsx 更新每个人的状态和面试反馈；一面通过的写进约下一轮的名单草稿，放进「反馈/等我确认」，我确认之前不要发给用人部门。
- 提示词框底部加技能：周五反馈汇总
- 工作空间：反馈（里面有「本周」和「等我确认」两个文件夹，汇总表_上周在面.xlsx 放在「反馈」里）
- 重复：每天　时间：现在往后两分钟（课上用）
- 点确定，再把 面试官反馈群.txt 放进「反馈/本周」

## 跑完以后

看汇总表三行和名单草稿，挑一处让 Agent 改（比如薪资超预算的那一条有没有标出来、有没有替专员回候选人），再跑一次。跑完把重复改回每周五，或者先暂停。
