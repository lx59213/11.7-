# 做网页说明：把报价的任务说明做成业务员和经销商打开就能用的网页

## 做什么

把第 1 项那种五行任务说明交给 Agent，让它做成一个网页。业务员和经销商双击这个网页文件就能报价，不用装软件，也不用会用 Agent。

## 三步

1. 新开一个对话，把 价格表_2026Q4.xlsx、运费表_2026年11月.xlsx 拖进去，再整段贴 任务说明_报价.md 里五行任务说明和最后那句话。
2. Agent 做好以后，双击它写出来的 .html 文件打开，填一单：客户、数量、产品、插头、报法、定制。
3. 照学员页 10-2 再填三单，对一下单价、总价和不报的那单。哪一单不对，告诉 Agent 应该是多少、为什么，让它改。

## 要对的三件事

- 单价等于数量档的价，加定制，报到港时再加运费；饮水机插头欧规、英规同价，只记在报价上；总价等于单价乘数量。
- 规则外的单不报，写明原因：不到 300 件、定制不到 1,000 件（贴 logo、彩盒都是 1,000 件起），转给业务员；10,000 件及以上不报，转销售主管郑凯。港口不在运费表里的只报 FOB，到港价转业务员问货代。
- 每一单都在报价记录里留一行。

## Agent 慢或出不来

打开“做好的网页”文件夹里的 报价网页.html，双击就能用，先做第 3 步。

## 给同事用

把 .html 文件发给同事，用浏览器打开就行。网页里的记录只在当前这个窗口里，关掉就清空；要长期保存，再对 Agent 说：每一笔记录同时存成一个表格文件。价格表、运费表改了，把新表拖给 Agent，说“照新表改网页”，改完再试三单。

## 自己岗位的网页

把任务说明里的“Agent 当谁、材料、要什么样、不能答应、交回前先做”换成自己岗位的，材料换成自己的表。“不能答应”一定写：什么情况网页不能自己定，要交给谁。
