# 练习记录（示例）

这是我们写的示例，每个人的知识库不一样，错的题也会不一样。

## 一、旁边的人从 新人考题 里挑的三道（不是第 2、7、10 题）

3　客户问：滤网多久换一次？
Agent 答：正常使用 2 到 3 个月换一次，养猫养狗的家庭 1 到 2 个月。滤网不要水洗。
出处：退换规则/耗材更换周期.md
旁边的人打钩：对，写了出处

4　客户说机器跑完总是回不了充电座，怎么办？
Agent 答：这是 E8。先看充电座灯亮不亮，再把座周围 0.5 米内清空，用干布擦两边的金属触点，最后手动放回座上试充电。还不行就寄修。
出处：故障代码/E8_回不了充电座.md
旁边的人打钩：对，写了出处

8　客户在黑色地毯上一开机就报 E3，怎么办？
Agent 答：黑色地毯会被当成悬崖，这种不算故障。先用干软布擦机器底部的 4 个小窗，再在 App 里把地毯设成禁区或开地毯模式。
出处：故障代码/E3_悬崖传感器.md、老员工经验/深色地毯报E3.md
旁边的人打钩：对，写了出处
