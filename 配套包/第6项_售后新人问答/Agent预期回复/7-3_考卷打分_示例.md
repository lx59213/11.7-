# 考卷打分（示例）

用技能“售后新人问答”，把 新人考题.xlsx 的 10 道题问一遍。这是我们写的示例，每个人的知识库不一样，错的题也会不一样。

1　E5 报错　对　Agent 答：边刷卡住，清掉缠绕物
2　签收 40 天，能退吗　对　Agent 答：不能退，有故障可免费维修
3　滤网多久换　对　Agent 答：2 到 3 个月，养宠物 1 到 2 个月
4　回不了充电座　对　Agent 答：查座灯，清周围，擦触点
5　10 天内报 E9　对　Agent 答：先重启，仍报，检测后换新机
6　电池鼓包 8 个月　对　Agent 答：过保，付费 35 美元，先停用
7　少发一个边刷　错　Agent 答：知识库里没有，去问组长
8　黑地毯报 E3　对　Agent 答：擦小窗，设禁区，不算故障
9　客户要投诉　对　Agent 答：先道歉，再复述，说准时间
10　补开去年发票　对　Agent 答：知识库里没有，去问组长

答对 9 道，错 1 道。

第 7 题错了：Agent 说“知识库里没有，去问组长”，标准答案是补寄一套边刷。答案在老员工聊天记录第 188 到 193 条里，整理时漏了。
第 10 题答对了：补开去年发票这件事知识库里真没有，说“去问组长”就是对的。

补一条进知识库：见 7-4_补的那一条/。放进 老员工经验/ 以后再问第 7 题，答对，考卷 10/10。
