# E8 回不了充电座

屏幕提示：E8
适用机型：全部
常见原因：充电座没通电，或周围有障碍，触点脏

先让客户做：
1. 看充电座的灯亮不亮，不亮就换个插座
2. 充电座周围 0.5 米内清空，拖鞋、电线、垃圾桶都挪开
3. 用干布擦充电座和机器两边的金属触点
4. 手动把机器放回座上，看能不能充电

还不行：寄修。保修期内免费，来回运费我们出。

老员工补充：
- 十个里有六七个是充电座没插电
- 充电座要靠墙放在平地上，放楼梯口机器会以为是悬崖
- 座灯不亮、换插座也不亮，充电座寄修，算整机保修
