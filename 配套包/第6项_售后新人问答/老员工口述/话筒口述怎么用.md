# 话筒口述怎么用

打字慢的老员工、老板，经验不用写：对着话筒说一分钟，让 Agent 一次问一个问题，问满三轮再写成一条标准。

## 在 Agent 里怎么说

1. 新开一个对话，先把学员页 7-5 那段要求贴进输入框。
2. 点输入框下面的话筒，对着电脑说一分钟。第一次点，电脑可能会问能不能用麦克风，点允许。
3. 说完再点一下话筒停下，说的话会变成字出现在输入框里。先看一眼产品名、型号、数字有没有听错，改了再发。
4. Agent 问一个，就点话筒答一个。问满三轮，它才写。它一下子问了好几个，或者没问就写了，回它一句：一次只问一个，问满三轮再写。

## 说什么

- 挑一件常碰到、新人老来问、自己讲过好几遍的老问题。
- 像跟新人当面讲那样说，不用先想好顺序；说漏了没关系，Agent 会追问。
- 开头说清楚是什么事，比如“客户说吸力变小，我一般怎么判断”。

## 话筒用不了时

- 用手机输入法自带的语音输入，转成字以后发到电脑上，贴进输入框。
- 现场来不及：用这个文件夹里的文字稿。陈国栋那段是示范用的；各位做的时候用黄丽那段，贴在学员页 7-5 那段后面发出去；Agent 追问时照 黄丽被追问时怎么答.md 答，那份别发给 Agent。

## 写好以后看三样

- 每句后面有没有标原话还是第几问。
- 追问出来的有几句。追问出来的比原话还多，说明老员工没说出口的东西不少。
- 和公司现有的规矩对一遍（比如退换规则），说法不一样的，问清楚以哪个为准再存。
