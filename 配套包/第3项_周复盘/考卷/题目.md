# 第 3 项考卷 · 题目（记分用，跑的时候不发给 Agent）

考的是：把站点日报交给 Agent 出上周的周复盘，它找出了几处不对劲、有没有报错。表里事先埋了 20 处不对劲（前 12 处在上周，后 8 处是前 5 周里录错的，会把“前 5 周同一天”的平均拉偏），另有 3 处看着像、其实活动解释得通，不该报。
示范里讲过的三处和可售库存的空格不算题，报了不加分也不算错（见标准答案最后一节）。

每题判三件：找到没有（站点、商品、日期和哪类问题都对才算找到）；原表第几行写对没有；两个数写对没有（可以差一点点，四舍五入、算合计还是算平均都行，和答案同一个意思就算对）。

## 不该报的

不该报 1. 有一处销量或广告花费涨了，活动栏写的是秒杀、优惠券或直播之一，涨跌和单价都解释得通。周复盘有没有把它当成不对劲报出来？报了算报错一处；写明“有活动，不算不对劲”不算错。
不该报 2. 有一处销量或广告花费涨了，活动栏写的是秒杀、优惠券或直播之一，涨跌和单价都解释得通。周复盘有没有把它当成不对劲报出来？报了算报错一处；写明“有活动，不算不对劲”不算错。
不该报 3. 有一处销量或广告花费涨了，活动栏写的是秒杀、优惠券或直播之一，涨跌和单价都解释得通。周复盘有没有把它当成不对劲报出来？报了算报错一处；写明“有活动，不算不对劲”不算错。

## 记分

- 找到几处：20 处里找到几处（同一处换了说法、拆成两条，只算一处）。
- 行号对几处、两个数对几处：在找到的里面数。
- 报错几处：写成“不对劲”、但不在这 20 处、也不在示范那三处里的，每条算一处；不该报的三处报了，每处算一处。
- 每遍还记：从发出到能用花了多久（分钟）、人改了几处（告诉 Agent “这条不对、改一下”算一处）。
