# 第 4 项：同一件事，两种做法各跑一遍

同一个 Agent，两种做法各新开对话，各跑三遍。两种做法拖进去的文件一样：露营灯_参数单.xlsx、检测报告_NB-2026-08817.pdf、不能说的词.md、德语来信.eml、英文来信.eml。考卷文件夹里的东西都不拖进去。

要写出五份：页面卖点、客服话术、给德国买家的邮件、回德国买家的来信、回英国买家的来信。

## 只说一句

拖进文件，只说这一句：

帮我把这款露营灯写成商品页卖点、客服话术和给德国买家的邮件三版，再把这两封来信回了。

## 用课上的做法（照第 4 项）

拖进文件，一段一段贴，每段等它写完再贴下一段：

1. 写三版（第 1 步那段话；课上为了一屏放得下只写亮度、续航、防护三句，这里不限，和只说一句写的一样多）：

照参数单写同一件事的三版：平台页面的卖点、国内客服的话术、德国买家的邮件。三版都写这款灯的主要卖点。参数单上没有的不写，不能说的词不用。德语邮件逐句附中文回译。

2. 三版并排对单子（第 2 步，原话）：

三版放在一起，对着参数单和检测报告逐句看。对不上的句子标出来，每句写一句原因。再说哪一版现在就能发，不能发的改成能发的。德语那版看中文回译，不看德语。

3. 回德语来信（第 3 步，原话）：

回这封德语来信。语气客气，不替我们答应退款或赔偿；我们页面上把灯写成了“防水”，这是写错了，信里要认错。写完逐句译回中文，放在德语旁边。

4. 回英语来信（练习那段话里写英文回信的部分）：

回英国买家的英文来信，逐句附中文回译。参数单上没有的不写，不能说的词不用，每句后面标上参数单或检测报告里的依据。买家问到参数单上没有的事，或不能答应的事，信里不要替公司答应，写成“我先问清楚再回复”。写完先指出哪一句对不上参数单，不要自己编。

5. 看回译（第 3 步的做法）：三份外语只看中文回译，逐句对参数单，语气硬的、替公司答应了的、对不上单子的，对 Agent 说“第几句怎么改”，改完再看一遍回译。

## 每遍记什么

每遍拿“题目.md”里的记分表对五份东西，再记一张总表：

- 从发出到五份都能发：从发出第一句话算起，到五份都改到清单上一条都不违反为止，自己改的时间也算。
- 违反几条：Agent 交回的结果（人改之前）照清单数。课上的做法第 5 步之前那一版算“交回的结果”。
- 人改了几处：为了改到一条都不违反，自己动手改或让 Agent 重改的句子，一句算一处。
