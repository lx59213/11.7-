# 练习：同一份参数单，再写给外贸同事和英国买家

## 贴给 Agent

照参数单写两版。一版是给外贸同事的一页产品简介，中文，外贸照它回海外经销商的询盘；一版是回英国买家的英文来信，逐句附中文回译。参数单上没有的不写，不能说的词不用，每句后面标上参数单或检测报告里的依据。买家问到参数单上没有的事，或不能答应的事，信里不要替公司答应，写成“我先问清楚再回复”。写完先指出哪一句对不上参数单，不要自己编。

## 写完，自己对一遍

| 版本 | 第几句 | 这句话 | 对着参数单或检测报告的哪一行 | 用了不能说的词吗 | 对得上吗 |
| --- | --- | --- | --- | --- | --- |
| 外贸用的简介 | 1 | | | | |
| 外贸用的简介 | 2 | | | | |
| 英文回信 | 1 | | | | |
| 英文回信 | 2 | | | | |

英文回信让 Agent 逐句译回中文，放在英文旁边，只看回译。买家问到参数单上没有的事（比如保修），回信里写“我先问清楚再回复”。挑出能发的那一版，发到班级群。

材料里的公司、人名、订单号、检测中心都是编的。
