# 台上口径：定形状时这样答

【示例／虚构】你演的是猫狗家的外贸业务员周晓。AI 问的顺序和说法会跟下面不一样，意思对上就行。
目标：让台下看到“它问一个、带建议、我回‘对’或改一句”，并选到**销售**那套结构。答两三个就可以说“按你建议的来，继续。”，让它自己把剩下的走完。

## 开工

发学员页上那句短的：

> 读 知识库/README.md，带我搭知识库。

它应该先试读三个格式样例，用两三行大白话报：能读写、能读哪几种格式、接下来要问十个左右的问题。然后直接问第一个。从这里起留意它说的话：出现“卡”“字段”“看板”“视图”“待确认 1 处”这类词，就是没守住 README 的“跟人说话”。

## ① 定形状（十一问，照这个答）

| AI 大概会问 | 它的建议大概是 | 你这样答 |
| --- | --- | --- |
| 1. 你的岗位？管哪条业务？ | 给两个例子让你照着说 | “外贸业务员，我叫周晓。只管回海外经销商询盘，就是第一封回信。手上这三封询盘都是新客户，都还没回。捷克那封今天就得回，德国、迪拜的明天回。” |
| 2. 这个库给谁用？ | 先自己用，以后给新人看 | “对。” |
| 3. 天天打交道的是哪几样？ | 客户、每笔生意、每次来回；规定和产品 | “对。”（到这里它应该照**销售**那套出建议） |
| 4. 最常查的 5 件事？ | 价格、交期、定金、贴牌、证书 | “对。” |
| 5. 库分成这几块对吗？客户、商机、沟通、规定、产品，每块一页记什么 | 同左 | “对。” |
| 6. 每个客户记：地区、新老、做到哪一步、负责人、下次跟进、最要紧的事？ | 同左 | “对。” |
| 7. 每笔生意、每次来回记这几样？ | 生意：客户、产品、数量、做到哪一步、下次跟进、下一步；来回：客户、商机、日期、方式、说了什么 | **演示“改一句”**：“每笔生意再多记一样：到哪个港。” |
| 8. 对不上时谁说了算？ | 价格问主管，交期问跟单 | “价格、交期、付款问老陈。证书问阿梅。” |
| 9. 首页最想看什么？ | 本周要跟进、客户到哪一步了、最近沟通、要找人拍板的 | “对。” |
| 10. 资料在哪？A 桌面 B 文档 C 下载 D 微信 E 某个文件夹 F 不知道 | F，你去找 | “桌面上有个‘猫狗家资料’文件夹。老板的通知是在微信里收的。” |
| 11. 在微信收到的文件里，用这些词找，对吗？ | 询盘、报价、价格表、交期、定金、证书…… | “对。”（因为说了微信才问；只说文件夹的话，它不该问这一个，也不该问格式） |

它说出“你的库打算这样分”以后，看一眼每笔生意记的那几样里有没有“到哪个港”（是你的原话，不该被改成“目的港”），然后回：

> 就这样。

**要它注意的地方（台上可以点一句）：**

- 第 1 问你顺口说的“都是新客户”“今天要回”，它会记进 raw/采访记录，后面填卡时当资料用。这就是“每句话有出处”。
- 第 7 问你改了一句，它给你看的分法就跟着变。库长什么样是你定的，不是套模板。

## ③ 找资料

它会去桌面的“猫狗家资料”和微信收文件的文件夹找，列出 8 个，全打 ✓。“猫狗家资料”是你指定的文件夹，里面每一份都该打 ✓，包括文件名看不出关系的“跟单群聊天”和 2025 年的“回询盘做法”。回：

> 按你推荐的。

现场电脑上没有微信那份老板通知的话，它会只列出 7 个，没关系。也可以提前把 `原始资料_示例虚构/` 里的 8 份都放进桌面的“猫狗家资料”。

## ④ 填库

不用说话。台上可以让大家看 Obsidian 左边的页一张张长出来，再念一批的三行进度，应该是“第 1 批看完了：……新整理了几页……有几处要找人拍板”这样的大白话。时间不够就停在这里，切到 `做好的示例库/` 讲 ⑤。

## ⑤ 做首页（在做好的示例库上演示）

打开 `做好的示例库/我的公司AI/知识库` 的首页，指给大家看：

1. **本周要跟进**：三个客户、三笔生意，都过了 1 到 2 天（库是按 11-05 做的，11-07 打开就是“过了”）。
2. **客户到哪一步了**：三个都在“新询盘”。
3. **要找人拍板的、还缺资料的**：交期计算那页的 `#待确认`（排产 25 天还是 30 天），几处 `#待补`。
4. 点“关系图谱”标签：五种颜色是五个目录，灰的是原件，浅棕的是来源摘要。

然后现场演一次改首页，在 AI 工具里（工作空间选 `做好的示例库/我的公司AI`）说：

> 首页再加一块，按地区分。

它应该只改 `看板.base` 和 `首页.md`，首页多出“客户按地区”：德国、捷克布拉格、阿联酋迪拜各一个。

## 可以顺手演的

- **“不知道”**：AI 问一个上面没有的，就答“这个我说不清”。它应该用自己的建议，接着问下一个，不追问。
- **它在 ① 以外问你**：这是 README 不让的。可以当场回“停。照 知识库/README.md 来，只在定形状时问我。”给大家看怎么拉回来。
