# 找资料提示（③ 用）

边界见 README.md ③ 第 3 步。下面是常见位置，找不到就跳过那一处，不要满盘乱找。

## 桌面、文档、下载

| 位置 | Mac | Windows |
| --- | --- | --- |
| 桌面 | `~/Desktop` | `C:\Users\用户名\Desktop`；开了 OneDrive 的常在 `C:\Users\用户名\OneDrive\Desktop`（中文系统可能叫 `OneDrive\桌面`） |
| 文档 | `~/Documents` | `C:\Users\用户名\Documents`；开了 OneDrive 的常在 `C:\Users\用户名\OneDrive\Documents`（或 `OneDrive\文档`） |
| 下载 | `~/Downloads` | `C:\Users\用户名\Downloads` |

Windows 上 `C:\Users\用户名` 可以用 `%USERPROFILE%`（PowerShell 里是 `$env:USERPROFILE`）。资料也常放在 D 盘、E 盘的某个文件夹，人说了才去。

## 微信收到的文件

人知道在哪最好：微信里对着文件点右键“在文件夹中显示”（Mac 叫“在 Finder 中显示”），或看“设置 → 账号与存储”（旧版叫“文件管理”）。

自己找，只在下面这几层按文件名找。**同一个微信文件夹里的 db_storage、Msg、Backup、Image、Video 这类子文件夹一律不进。**

| 版本 | 一般在哪（wxid_xxx 是每人不同的一串字符） | 有多准 |
| --- | --- | --- |
| Windows 旧版（3.x） | `C:\Users\用户名\Documents\WeChat Files\wxid_xxx\FileStorage\File\年-月\` | 多年没变，比较准。很多人改到了 D 盘，比如 `D:\WeChat Files\...` |
| Windows 新版（4.x） | `C:\Users\用户名\Documents\xwechat_files\wxid_xxx\msg\file\年-月\` | 拿不准：有的电脑是 `C:\Users\用户名\xwechat_files\...`，没有 Documents 这一层；也可能改到了别的盘 |
| Mac 新版（4.x） | `~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files/wxid_xxx/msg/file/年-月/` | 拿不准：xwechat_files 这一层比较确定，下面的 msg/file 是照 Windows 新版推的 |
| Mac 旧版（3.x） | `~/Library/Containers/com.tencent.xinWeChat/Data/Library/Application Support/com.tencent.xinWeChat/版本号/一串字符/Message/MessageTemp/一串字符/File/` | 拿不准：中间几层是随机字符，每个聊天一个文件夹 |
| 企业微信 | Windows 一般在 `Documents\WXWork\...\Cache\File\年-月\`；Mac 在 `~/Library/Containers/com.tencent.WeWorkMac/...` 下面 | 拿不准，最好请人右键“在文件夹中显示” |

Mac 上 `~/Library/Containers` 可能弹窗问“是否允许访问其他 App 的数据”。人点了不允许或工具报没权限，别再试，照 README.md ③ 第 4 步请人复制。

## 参考写法

用你自己的工具就行。只看文件名、大小、修改日期；关键词换成 我的知识库.md 里记的。

Mac（终端）：

```
find ~/Desktop ~/Documents ~/Downloads -maxdepth 4 -type f -not -path '*/.*' \( -iname '*报价*' -o -iname '*交期*' -o -iname '*询盘*' \) \( -iname '*.doc*' -o -iname '*.xls*' -o -iname '*.csv' -o -iname '*.ppt*' -o -iname '*.pdf' -o -iname '*.txt' -o -iname '*.md' -o -iname '*.png' -o -iname '*.jp*g' \) -exec stat -f '%z	%Sm	%N' -t '%Y-%m-%d' {} \; 2>/dev/null | head -200
```

Windows（PowerShell）：

```
$kw = '报价|交期|询盘'
$ext = '\.(docx?|xlsx?|csv|pptx?|pdf|txt|md|png|jpe?g)$'
$dirs = "$env:USERPROFILE\Desktop","$env:USERPROFILE\Documents","$env:USERPROFILE\Downloads"
Get-ChildItem -Path $dirs -Recurse -Depth 4 -File -ErrorAction SilentlyContinue |
  Where-Object { $_.Name -match $kw -and $_.Name -match $ext -and $_.FullName -notmatch '\\(AppData|WeChat Files\\[^\\]+\\(Msg|db_storage|Backup))\\' } |
  Select-Object -First 200 FullName, Length, @{n='修改日期';e={$_.LastWriteTime.ToString('yyyy-MM-dd')}}
```

PowerShell 显示中文乱码，先运行 `[Console]::OutputEncoding = [Text.Encoding]::UTF8` 再找。

人指定的文件夹：去掉关键词那一段，只留文件类型，里面的全列。比如 Mac：

```
find ~/Desktop/猫狗家资料 -maxdepth 4 -type f -not -path '*/.*' \( -iname '*.doc*' -o -iname '*.xls*' -o -iname '*.csv' -o -iname '*.ppt*' -o -iname '*.pdf' -o -iname '*.txt' -o -iname '*.md' -o -iname '*.png' -o -iname '*.jp*g' \) -exec stat -f '%z	%Sm	%N' -t '%Y-%m-%d' {} \; 2>/dev/null
```

Windows 就是把上面 PowerShell 里的 `$_.Name -match $kw -and` 删掉，`$dirs` 换成那个文件夹。

## 复制

Mac 用 `cp -p`，Windows 用 `Copy-Item`。
