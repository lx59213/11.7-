1. 价格怎么报
2. 多久能交货、能不能赶上客户要的日子
3. 定金怎么收
4. 能不能贴 logo、用客户自己的彩盒
5. 有没有证书，能不能发给客户

## 库分成哪几块

参照的示例：01_销售（每笔生意多记一样：到哪个港）

```
你的库打算这样分（照“销售”那套改的）：

分成 5 块：
- 客户：每个客户记一页
- 商机：每笔生意记一页
- 沟通：每次来回的邮件记一笔（电话、微信也算）
- 规定：报价、交期、付款、回信这些规定，一条一页
- 产品：一个产品一页
另外 3 块是固定的，不用你管：每份资料的要点、问过的问题、归不了类的。

每页记这些事：
- 每个客户：地区、新老、做到哪一步、负责人、下次跟进、最要紧的事
- 每笔生意：客户、产品、数量、到哪个港、做到哪一步、下次跟进、下一步
- 每次来回：客户、商机、日期、方式、说了什么
- 做到哪一步只填：新询盘、已报价、打样、谈判、成交、暂停

首页上放：本周要跟进的、客户到哪一步了、生意到哪一步了、最近沟通、要找人拍板的和还缺的。
资料去哪找：桌面的“猫狗家资料”文件夹，里面的全列给你挑；微信收到的文件里，找名字带询盘、报价、价格表、交期、定金、证书、通知的。
拿不准时问谁：价格、交期、付款问老陈；证书问阿梅。
```
