# 销售看板

**要用到的项**：客户卡的 `地区`、`新老`、`做到哪一步`、`负责人`、`下次跟进`、`最要紧的事`；商机卡的 `客户`、`产品`、`数量`、`做到哪一步`、`下次跟进`、`下一步`；沟通记录的 `客户`、`日期`、`方式`、`说了什么`。
目录名或项名改过的，下面照着换；没有商机卡的，删掉“生意到哪一步了”视图，“本周要跟进”只留客户那一行。

## 看板.base

```yaml
filters:
  and:
    - '!file.inFolder("_参考")'
    - '!file.inFolder("模板")'
    - 'note["示例"] != true'
formulas:
  follow_days: 'if(note["下次跟进"], (date(note["下次跟进"]) - today()).days, 999)'
  follow_label: 'if(formula.follow_days < 0, html("<span class=\"pill red\">过了" + formula.follow_days.abs().toString() + "天</span>"), if(formula.follow_days == 0, html("<span class=\"pill red\">今天</span>"), if(formula.follow_days == 1, html("<span class=\"pill orange\">明天</span>"), html("<span class=\"pill grey\">还有" + formula.follow_days.toString() + "天</span>"))))'
  marks: 'html(if(file.hasTag("待确认"), "<span class=\"pill orange\">要拍板</span> ", "") + if(file.hasTag("待补"), "<span class=\"pill grey\">缺资料</span>", ""))'
summaries:
  几页: 'values.length'
properties:
  file.name:
    displayName: 页
  formula.follow_label:
    displayName: 跟进
  formula.marks:
    displayName: 标记
views:
  - type: table
    name: 现在做到哪
    filters:
      and:
        - 'file.path == "我的知识库.md"'
    order:
      - file.name
      - note.做到哪一步
      - note.下一步
      - note.更新
    columnSize:
      file.name: 200
      note.做到哪一步: 100
      note.更新: 120
      note.下一步: 520
  - type: table
    name: 本周要跟进
    filters:
      and:
        - or:
            - 'file.inFolder("wiki/客户")'
            - 'file.inFolder("wiki/商机")'
        - 'formula.follow_days <= 7'
    order:
      - file.name
      - note.类型
      - note.做到哪一步
      - note.下次跟进
      - formula.follow_label
      - note.下一步
      - note.最要紧的事
    columnSize:
      file.name: 200
      note.类型: 90
      note.做到哪一步: 100
      note.下次跟进: 120
      formula.follow_label: 90
      note.下一步: 220
      note.最要紧的事: 220
    sort:
      - property: note.下次跟进
        direction: ASC
  - type: table
    name: 客户到哪一步了
    filters:
      and:
        - 'file.inFolder("wiki/客户")'
    groupBy:
      property: note.做到哪一步
      direction: ASC
    order:
      - file.name
      - note.地区
      - note.新老
      - note.负责人
      - note.下次跟进
      - note.最要紧的事
    columnSize:
      file.name: 200
      note.地区: 110
      note.新老: 90
      note.负责人: 90
      note.下次跟进: 120
      note.最要紧的事: 390
  - type: table
    name: 生意到哪一步了
    filters:
      and:
        - 'file.inFolder("wiki/商机")'
    groupBy:
      property: note.做到哪一步
      direction: ASC
    order:
      - file.name
      - note.客户
      - note.产品
      - note.数量
      - note.下次跟进
      - note.下一步
    columnSize:
      file.name: 200
      note.客户: 140
      note.产品: 140
      note.数量: 90
      note.下次跟进: 120
      note.下一步: 310
  - type: table
    name: 最近沟通
    filters:
      and:
        - 'file.inFolder("wiki/沟通")'
    order:
      - note.日期
      - file.name
      - note.客户
      - note.方式
      - note.说了什么
    columnSize:
      note.日期: 120
      file.name: 200
      note.客户: 140
      note.方式: 90
      note.说了什么: 450
    sort:
      - property: note.日期
        direction: DESC
    limit: 10
  - type: table
    name: 要拍板的和还缺的
    filters:
      and:
        - 'file.inFolder("wiki")'
        - or:
            - 'file.hasTag("待确认")'
            - 'file.hasTag("待补")'
    order:
      - file.name
      - note.类型
      - formula.marks
      - file.mtime
    columnSize:
      file.name: 200
      note.类型: 90
      formula.marks: 150
      file.mtime: 150
    sort:
      - property: file.mtime
        direction: DESC
  - type: table
    name: 还没整理的原件
    filters:
      and:
        - 'file.inFolder("raw")'
        - 'file.basename != "放原始资料"'
        - 'file.backlinks.length == 0'
    order:
      - file.name
      - file.ext
      - file.size
      - file.mtime
    columnSize:
      file.name: 200
      file.ext: 70
      file.size: 90
      file.mtime: 150
  - type: table
    name: 库里都有什么
    filters:
      and:
        - 'file.inFolder("wiki")'
        - 'file.hasProperty("类型")'
    groupBy:
      property: note.类型
      direction: ASC
    order:
      - file.name
      - note.状态
      - note.更新
    columnSize:
      file.name: 200
      note.状态: 90
      note.更新: 120
    summaries:
      file.name: 几页
```

## 常见改法

- **“首页再加一块，按地区分”**：在 `views:` 下面加这一段，再在首页加一节 `## 客户按地区` 和 `![[看板.base#客户按地区]]`。

  ```yaml
    - type: table
      name: 客户按地区
      filters:
        and:
          - 'file.inFolder("wiki/客户")'
      groupBy:
        property: note.地区
        direction: ASC
      order:
        - file.name
        - note.做到哪一步
        - note.负责人
        - note.下次跟进
      columnSize:
        file.name: 200
        note.做到哪一步: 100
        note.负责人: 90
        note.下次跟进: 120
  ```

- **“只看新客户”**：在“客户到哪一步了”的 `filters` 的 `and` 里加一行 `'note["新老"] == "新客户"'`，视图名改成“新客户到哪一步了”，首页一起改。
- **“按负责人分”**：照“按地区分”那一段，`property` 换成 `note.负责人`，视图名叫“客户按负责人”。
- **“本周要跟进改成两周”**：把 `'formula.follow_days <= 7'` 改成 `<= 14`，视图名和首页一起改成“两周内要跟进”。
- **“客户一个一个排开看”**：加一个 `type: cards` 的视图，写法见 `01_通用看板.md` 的“用卡片的样子看”。
- **“做到哪一步按先后排”**：见 `01_通用看板.md` 常见改法的最后一条。
