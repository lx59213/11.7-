# 老板看板

**要用到的项**：重点事卡的 `负责人`、`做到哪一步`、`最晚哪天做完`、`下次跟进`、`最要紧的事`；大客户卡的 `多重要`、`关系`、`负责人`、`下次跟进`、`最要紧的事`；`wiki/制度/` 的页。
目录名或项名改过的，下面照着换；没有大客户卡的，删掉“大客户”视图，“要盯的事”里删掉大客户那一行。

## 看板.base

```yaml
filters:
  and:
    - '!file.inFolder("_参考")'
    - '!file.inFolder("模板")'
    - 'note["示例"] != true'
formulas:
  follow_days: 'if(note["下次跟进"], (date(note["下次跟进"]) - today()).days, 999)'
  follow_label: 'if(formula.follow_days < 0, html("<span class=\"pill red\">过了" + formula.follow_days.abs().toString() + "天</span>"), if(formula.follow_days == 0, html("<span class=\"pill red\">今天</span>"), if(formula.follow_days == 1, html("<span class=\"pill orange\">明天</span>"), html("<span class=\"pill grey\">还有" + formula.follow_days.toString() + "天</span>"))))'
  marks: 'html(if(file.hasTag("待确认"), "<span class=\"pill orange\">要拍板</span> ", "") + if(file.hasTag("待补"), "<span class=\"pill grey\">缺资料</span>", ""))'
summaries:
  几页: 'values.length'
properties:
  file.name:
    displayName: 页
  formula.follow_label:
    displayName: 跟进
  formula.marks:
    displayName: 标记
views:
  - type: table
    name: 现在做到哪
    filters:
      and:
        - 'file.path == "我的知识库.md"'
    order:
      - file.name
      - note.做到哪一步
      - note.下一步
      - note.更新
    columnSize:
      file.name: 200
      note.做到哪一步: 100
      note.更新: 120
      note.下一步: 520
  - type: table
    name: 要盯的事
    filters:
      and:
        - or:
            - 'file.inFolder("wiki/重点事")'
            - 'file.inFolder("wiki/大客户")'
        - or:
            - 'formula.follow_days <= 7'
            - 'note["做到哪一步"] == "卡住了"'
            - 'note["关系"] == "有风险"'
    order:
      - file.name
      - note.类型
      - note.负责人
      - note.做到哪一步
      - note.关系
      - formula.follow_label
      - note.最要紧的事
    columnSize:
      file.name: 200
      note.类型: 90
      note.负责人: 90
      note.做到哪一步: 100
      note.关系: 90
      formula.follow_label: 90
      note.最要紧的事: 340
    sort:
      - property: note.下次跟进
        direction: ASC
  - type: table
    name: 等你拍板的
    filters:
      and:
        - 'file.inFolder("wiki")'
        - 'file.hasTag("待确认")'
    order:
      - file.name
      - note.类型
      - file.mtime
    columnSize:
      file.name: 200
      note.类型: 90
      file.mtime: 150
    sort:
      - property: file.mtime
        direction: DESC
  - type: table
    name: 重点事到哪一步了
    filters:
      and:
        - 'file.inFolder("wiki/重点事")'
    groupBy:
      property: note.做到哪一步
      direction: ASC
    order:
      - file.name
      - note.负责人
      - note.最晚哪天做完
      - note.下次跟进
      - note.最要紧的事
    columnSize:
      file.name: 200
      note.负责人: 90
      note.最晚哪天做完: 120
      note.下次跟进: 120
      note.最要紧的事: 470
  - type: table
    name: 大客户
    filters:
      and:
        - 'file.inFolder("wiki/大客户")'
    groupBy:
      property: note.关系
      direction: ASC
    order:
      - file.name
      - note.多重要
      - note.负责人
      - note.下次跟进
      - note.最要紧的事
    columnSize:
      file.name: 200
      note.多重要: 90
      note.负责人: 90
      note.下次跟进: 120
      note.最要紧的事: 500
  - type: table
    name: 最近改过的制度
    filters:
      and:
        - 'file.inFolder("wiki/制度")'
        - 'file.mtime > now() - "30d"'
    order:
      - file.name
      - note.类型
      - note.状态
      - file.mtime
    columnSize:
      file.name: 200
      note.类型: 90
      note.状态: 90
      file.mtime: 150
    sort:
      - property: file.mtime
        direction: DESC
  - type: table
    name: 要拍板的和还缺的
    filters:
      and:
        - 'file.inFolder("wiki")'
        - or:
            - 'file.hasTag("待确认")'
            - 'file.hasTag("待补")'
    order:
      - file.name
      - note.类型
      - formula.marks
      - file.mtime
    columnSize:
      file.name: 200
      note.类型: 90
      formula.marks: 150
      file.mtime: 150
    sort:
      - property: file.mtime
        direction: DESC
  - type: table
    name: 还没整理的原件
    filters:
      and:
        - 'file.inFolder("raw")'
        - 'file.basename != "放原始资料"'
        - 'file.backlinks.length == 0'
    order:
      - file.name
      - file.ext
      - file.size
      - file.mtime
    columnSize:
      file.name: 200
      file.ext: 70
      file.size: 90
      file.mtime: 150
  - type: table
    name: 库里都有什么
    filters:
      and:
        - 'file.inFolder("wiki")'
        - 'file.hasProperty("类型")'
    groupBy:
      property: note.类型
      direction: ASC
    order:
      - file.name
      - note.状态
      - note.更新
    columnSize:
      file.name: 200
      note.状态: 90
      note.更新: 120
    summaries:
      file.name: 几页
```

## 常见改法

- **“只看某个负责人的”**：在那个视图的 `filters` 的 `and` 里加 `'note["负责人"] == "老陈"'`。
- **“按团队分”**：照 `02_销售看板.md` 的“按地区分”那一段，目录换成 `wiki/重点事`，`property` 换成 `note.负责人`，视图名叫“重点事按负责人”。
- **“最近改过的改成 7 天”**：把 `"30d"` 改成 `"7d"`，首页标题一起改。
- **“看看各个团队”**：加一个 `type: cards` 的视图，名字叫“各个团队”，目录 `wiki/团队`，`order` 写 `file.name`、`note.负责人`、`note.看哪个数`。
