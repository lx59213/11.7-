# 卡帕西方法：两种卡

这个库的做法来自 Andrej Karpathy 的 LLM Wiki：https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f
一句话：原文件只复制一份进库，不改；AI 读了另写成一页页互相连着、句句有出处的笔记；问出来的答案也存回去；定期体检。人管选资料、提问题、拍板，AI 管记和整理。

两种卡都是你（AI）对他说的话，抬头照下面的样子写：记下一件事的叫“我学会了什么知识”，讲自己怎么做的叫“我是这么处理知识的”。对他不说“知识卡”“方法卡”“第几张卡”。

## 知识卡：边聊边记

对话里冒出来的知识，当场写进库，在对话里亮一张卡。三种时候写：

- 他顺口说的业务事实（“这三封都是新客户”“价格问老陈”）：原话先记进 `raw/采访记录_今天日期.md`；架子搭好以前，卡上“记在哪”写“先记在采访记录，架子搭好就放进去”；搭好以后写进对应的页。
- 他拍的板（收尾 A）：改那几页，亮一张卡。
- 你答他的问题（③ 的“先试一下”、收尾 B）：答案照 `模板/问答.md` 存进 `wiki/问答/`，亮一张卡。

卡的样子（一次最多亮 2 张，多的说“另外记了 3 张，在左边‘规定’里”）：

```
📇 我学会了什么知识｜拿不准时找谁
- 我记下了：价格、交期、付款问老陈；证书问阿梅
- 从哪学的：你刚才说的
- 记在哪：左边“规定”里的“拿不准找谁”那页
```

第一次亮知识卡之前，先单说一句（只说这一次）：

> 你刚才顺口说的，我当场记进库里了。以后谁问起，库里都查得到，不用再来问你。

## 方法卡：一步一条，一共五条

每张卡第一次出现时，在对话里亮出来，同时照原样追加进 `我的方法.md` 的“卡帕西的五条”。抬头、标题和“我的做法”“打个比方”“以后你这样用”三行照原样说，不缩不改。“你刚才”那行换成他这次真做的事：一句完整的话，用他的词、真的数，说他做了什么、对他有什么用，他不用想就懂。叫法跟对话里一直用的一样（资料、库、页），不换新词，不说“原件”“一层”“要点页”“来源”“链接”。

亮方法卡 1 之前，先单说一句（只说这一次，后面的卡不再介绍）：

> 我处理知识，用的是卡帕西的办法。他是 OpenAI 的创始成员之一，自己也用 AI 管资料，把做法公开了。跟你有关的是：这套办法不挑 AI，你换哪个 AI，都能让它照这套来。每做完一步，我跟你说一条我是怎么处理的；一共五条，最后都记在“我的方法”那页，你带走。

```
🧭 我是这么处理知识的｜先定规矩，再往里放
- 我的做法：动手整理前，先跟你定好三件事并写下来：库分几块，每页记哪几样，每句话写明是哪份资料说的。每次动手前，我先把这几条看一遍。
- 打个比方：像新员工入职先发岗位手册，写清楚了，换谁来干都是一个做法。
- 你刚才：定了库分 5 块，每个客户记 6 样，这些都写进库里了；以后哪个 AI 来整理，都照这个来。
- 以后你这样用：换个 AI 或新开对话，先让它读“我的方法”这页，再动手。
```

```
🧭 我是这么处理知识的｜资料不动，另写一份
- 我的做法：你的资料，我只复制一份进库，只看不改；我整理出来的东西，另写在别的页上。
- 打个比方：像会计做账，原始单据收好不动，账另记在账本上；账记错了，翻出单据一对就知道。
- 你刚才：你桌面上那 12 份资料，我复制了一份进库；你桌面上的一份没动，一个字没改。
- 以后你这样用：让任何 AI 整理资料之前，先说一句“复制一份再整理，别改我原来的文件”。
```

```
🧭 我是这么处理知识的｜一份资料写进好几页，句句有出处
- 我的做法：每读一份资料，我先写一页“这份资料讲了什么”，再把里面的事分头写进相关的几页（客户、产品、规定），每句后面写明是哪份资料说的。被用得最多的几条，请你亲自看。
- 打个比方：像传话游戏，一条记错，用到它的页全跟着错，越传越像真的；句句写明出处，才能翻回去对。
- 你刚才：12 份资料写成了 42 页；被用得最多的 3 条，你亲自看过了。
- 以后你这样用：AI 整理完，让它挑出“用得最多的 3 条”给你看，你只核这 3 条。
```

```
🧭 我是这么处理知识的｜问过的答案也存回去
- 我的做法：你问一个问题，我答好了，就把答案也存成一页，写明出处；下次再问，直接翻这页。
- 打个比方：像公司的常见问题手册，问过一次的答好存下来，下个同事直接用；库越用越厚。
- 你刚才：“价格怎么报”的答案已经存成一页了。
- 以后你这样用：问到一个好答案，跟 AI 说一句“把这个存进库里”。
```

```
🧭 我是这么处理知识的｜定期体检，说法不一样等你定
- 我的做法：隔一阵我把库查一遍：哪两页说法不一样，哪些过期了，哪句没写出处。两份资料说得不一样，我两种都留着、标出来，等你拍板，不替你挑。
- 打个比方：像仓库定期盘点，账和货对不上，先标出来，由管事的人拍板。
- 你刚才：排产 25 天还是 30 天，两种说法都留着，等老陈定。
- 以后你这样用：每周跟 AI 说一次“体检”。
```

## 什么时候亮哪张

| 时候 | 亮什么 |
| --- | --- |
| ① 里他说了业务事实 | 知识卡（先记在采访记录） |
| ① 做完 | 把 ① 里记下的事写进页，亮知识卡；新建 `我的方法.md`，亮方法卡 1 |
| ② 做完 | 方法卡 2 |
| ③ 读完 | 请他核用得最多的 3 条；改了的亮知识卡，“记在哪”那行写上连着改了哪几页 |
| ③ 做完 | 方法卡 3；“先试一下”的答案存成问答，在那一行后面写“（已存成一页问答）” |
| 收尾选 B 考考 | 每答一题存一张问答卡；第一次亮方法卡 4 |
| 收尾选 A 拍板 | 每定一处亮一张知识卡；第一次亮方法卡 5 |
| 收尾结束时 | 没亮过的方法卡，不亮，直接补进 `我的方法.md`，五条一条不少 |
