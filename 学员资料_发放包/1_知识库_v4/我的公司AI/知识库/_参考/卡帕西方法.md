# 卡帕西方法：知识卡和方法卡

这个库的做法来自 Andrej Karpathy 的 LLM Wiki：https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f
一句话：原件放一层不动；AI 读了另写成一页页互相连着、句句有出处的笔记；问出来的答案也存回去；定期体检。人管选资料、提问题、拍板，AI 管记和整理。

## 知识卡：边聊边记

对话里冒出来的知识，当场写进库，在对话里亮一张卡。三种时候写：

- 他顺口说的业务事实（“这三封都是新客户”“价格问老陈”）：原话先记进 `raw/采访记录_今天日期.md`；架子搭好以前，卡上“存在”写“先记在采访记录，架子搭好就放进去”；搭好以后写进对应的页。
- 他拍的板（收尾 A）：改那几页，亮一张卡。
- 你答他的问题（③ 的“先试一下”、收尾 B）：答案照 `模板/问答.md` 存进 `wiki/问答/`，亮一张卡。

卡的样子（一次最多亮 2 张，多的说“另外记了 3 张，在左边‘规定’里”）：

```
📇 知识卡｜拿不准时找谁
- 记了：价格、交期、付款问老陈；证书问阿梅
- 从哪来：你刚才说的
- 存在：规定 → 拿不准找谁
```

## 方法卡：一步一条，一共五条

每张卡第一次出现时，在对话里亮出来，同时照原样追加进 `我的方法.md` 的“卡帕西的五条”。“你刚才”那行用他这次真做的事说。

```
🧭 方法卡 1｜先定规矩，再往里放
- 卡帕西的做法：先写好规矩：库分几块、每页记什么、出处怎么写；AI 每次先读规矩再动手
- 为什么：规矩定了，换哪个 AI 来写都是一个样，库不会越写越乱
- 你刚才：定了分 5 块，每个客户记 6 样
```

```
🧭 方法卡 2｜原件不动，笔记另写
- 卡帕西的做法：原件单放一层，只放不改；AI 读完另写笔记
- 为什么：笔记写错了，回原件一对就知道；原件永远是真的
- 你刚才：12 份原件复制进来，原来的一个没动
```

```
🧭 方法卡 3｜读一份，改一串，句句有出处
- 卡帕西的做法：每读一份资料，先记一页要点，再把里面的事写进相关的几页，每句标是哪份资料；他自己不撒手，引用最多的几条亲自看
- 为什么：页和页互相引用，一条记错，引用它的页全跟着错，越传越像真的；有出处才对得回去
- 你刚才：12 份资料写成了 42 页，用得最多的 3 条你亲自核了
```

```
🧭 方法卡 4｜问过的答案也存回去
- 卡帕西的做法：问一次、答一次，好答案存成一页，下次直接用
- 为什么：库不是只进不出，越用越厚
- 你刚才：“价格怎么报”已经存成一页问答
```

```
🧭 方法卡 5｜定期体检，矛盾不替你选
- 卡帕西的做法：隔一阵让 AI 查一遍：哪两页说法打架、哪些过期、哪页没人连、哪句没出处；对不上的两种都留着，等人定
- 为什么：资料会旧，规矩会变；拍板的是人，不是 AI
- 你接下来：每周跟我说一次“体检”
```

## 什么时候亮哪张

| 时候 | 亮什么 |
| --- | --- |
| ① 里他说了业务事实 | 知识卡（先记在采访记录） |
| ① 做完 | 把 ① 里记下的事写进页，亮知识卡；新建 `我的方法.md`，亮方法卡 1 |
| ② 做完 | 方法卡 2 |
| ③ 读完 | 请他核用得最多的 3 条；改了的亮知识卡，“存在”那行写上连着改了哪几页 |
| ③ 做完 | 方法卡 3；“先试一下”的答案存成问答，在那一行后面写“（已存成一页问答）” |
| 收尾选 B 考考 | 每答一题存一张问答卡；第一次亮方法卡 4 |
| 收尾选 A 拍板 | 每定一处亮一张知识卡；第一次亮方法卡 5 |
| 收尾结束时 | 没亮过的方法卡，不亮，直接补进 `我的方法.md`，五条一条不少 |
