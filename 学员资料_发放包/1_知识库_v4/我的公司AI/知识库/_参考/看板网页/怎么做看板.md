# 怎么做看板网页（写给 AI）

库整理完以后，或者他说“做个看板”时，照这页做。路径从 `知识库/` 算起。不跑脚本、不装东西，只读页、写文件。

## 1. 用哪种

只有一种样子，不问他。

## 2. 放文件

1. 把 `_参考/看板网页/看板.html` 复制成 `看板/看板.html`（没有 `看板/` 就建）。不能复制就读出来原样写，一个字不改。
2. 照第 3 节写 `看板/看板数据.js`。
3. 照第 4 节自查。第一次做时照 README ④ 那段话说；他单独要看板时说：

> 看板做好了。在 Obsidian 左边找到“看板”，右键“看板.html”，选“在默认应用中打开”；或者在电脑上打开 我的公司AI → 知识库 → 看板，双击“看板.html”。〖最急的一件，比如：Tomas 的询盘过了 1 天还没回。〗想看最新的，跟我说“更新看板”。

## 3. 看板数据.js

整个文件是一句 `window.KANBAN = { … };`，照 `_参考/看板网页/看板数据_示例.js`（猫狗家的完整例子）的样子写。

- 文字用英文双引号；文字里不要再有英文双引号，要引就用「」。每项后面加英文逗号。
- `页`：从 `知识库/` 算起的路径，带扩展名，比如 `"wiki/商机/Tomas-MG-W25-2026-11.md"`。网页靠它在 Obsidian 里打开那页，必须真有这个文件。
- 日子写 `"2026-11-06"`；`更新` 写到分钟 `"2026-11-06 08:30"`。
- `事`、`一句话`、`名` 原样显示在网页上，写大白话，不写路径和 wiki、raw 这类词。
- 哪项没有东西就写 `[]`，不删这一项，不编。

| 项 | 写成 | 从哪来 |
| --- | --- | --- |
| 库名 | `"周晓的知识库"` | `首页.md` 的大标题 |
| 库文件夹 | `"知识库"` | 知识库这个文件夹的名字（就是 Obsidian 里的库名），没改过就写“知识库” |
| 谁、岗位、业务 | 各一句 | `我的知识库.md`“谁的库” |
| 更新 | 写这个文件的时间 | |
| 成果 | 每样一条 `{ 块, 步, 名, 意味着, 页, 更新 }`，按做的先后排，最后一条最新 | 技能、智能体两个包每做完一步写一条；知识库这一块做完写一条。`块` 只写 知识库、技能、智能体、编队；`步` 如“第 2 步”，知识库写“建好”；`名` 是做成的东西；`意味着` 一句大白话：这对他们的业务有什么用；`页` 是做成的东西所在的页；`更新` 写到分钟。技能、智能体、编队这三块只写 `块`、`步`、`页`、`更新`、`评价`、`实话`：`评价` 写“还没比过”“好用”“一般”“不如不用”之一，照包里说的定；缺什么写进 `实话`，一句。看板网页一个技能、一个智能体画一张卡，自己写步名、亮格子、标评价，不写名字、分数。更新看板时，原有的成果照抄保留，只在最后加新的。哪项没有就写 `[]` |
| 数字 | 3 到 6 个 `{ 名, 数 }` | 用下面各项数。推荐：整理好的页、收进来的资料、今天明天要做的（过期的也算）、要找人拍板的、还缺的 |
| 分块 | 每块 `{ 名, 几页 }` | `wiki/` 下每个目录的页数，不算示例页、`放…` 占位页、index、log。顺序照 `我的知识库.md`“库分成哪几块”；固定的三块放最后，叫“资料要点”“问过的问题”“归不了类的”，没页的不写 |
| 待办 | `{ 事, 哪天, 页 }` | 页头里往后看的日子：名字带“跟进”“最晚”“截止”“到期”的项（`日期`、`资料日期` 记的是已经发生的，不算）。`事` 写那页的 `下一步`，没有就写一句要做什么。做到哪一步是成交、暂停、办完了的不写。同一件事客户页和商机页都有，只写一条，`页` 用商机页。规定页里写了“哪天起改”“哪天到期”的，也各写一条 |
| 要拍板 | `{ 事, 问谁, 页 }` | 正文里标 `#待确认` 的那一行；`问谁` 是标签后面写的人（`#待确认 问老陈` → `"老陈"`） |
| 还缺 | `{ 事, 页 }`，知道问谁就加 `问谁` | 正文里标 `#待补` 的那一行，一行一条 |
| 最近 | `{ 页, 块, 一句话, 更新 }`，最多 8 条 | 页头 `更新` 最近的页；`一句话` 照 `wiki/index.md` 里那行 |
| 资料 | `{ 名, 整理了吗, 页 }` | `raw/` 里每份原件（不算 `放原始资料.md`）。`名` 说成人话（“第四季度价格表”）；`wiki/来源/` 里有它那页写 `true`，没有写 `false`；`页` 写 `"raw/原文件名"` |

## 4. 自查

- 括号、引号成对，逗号是英文的。
- 每个 `页` 都真有这个文件；`块` 跟 `分块` 里的 `名` 一字不差。
- `数字` 里的数跟下面的条数对得上。

## 5. 以后

- “更新看板”：只重写 `看板/看板数据.js`（`更新` 改成现在），`看板.html` 不动。说“看板更新好了，开着的话半分钟内自己会变。”
- 要的改动看板上没有（加一块、换颜色、换排法）：说“看板的样子是定好的，上面的中文字可以改”。网页上显示的中文字（标题、小标题）可以改，别的代码不改。
- 他说看板上写着“数据有地方写错了”：照第 4 节查 `看板/看板数据.js`，改好说一句。
