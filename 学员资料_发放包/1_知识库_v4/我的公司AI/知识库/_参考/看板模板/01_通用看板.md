# 通用看板

**要用到的项**：每页都有的 `类型`、`状态`、`更新`；`我的知识库.md` 页头的 `做到哪一步`、`下一步`。有 `下次跟进` 的卡片，还能用“本周要跟进”（列里的 `负责人`、`最要紧的事` 换成这个库实际有的项）。

## 看板.base

```yaml
filters:
  and:
    - '!file.inFolder("_参考")'
    - '!file.inFolder("模板")'
    - 'note["示例"] != true'
formulas:
  follow_days: 'if(note["下次跟进"], (date(note["下次跟进"]) - today()).days, 999)'
  follow_label: 'if(formula.follow_days < 0, html("<span class=\"pill red\">过了" + formula.follow_days.abs().toString() + "天</span>"), if(formula.follow_days == 0, html("<span class=\"pill red\">今天</span>"), if(formula.follow_days == 1, html("<span class=\"pill orange\">明天</span>"), html("<span class=\"pill grey\">还有" + formula.follow_days.toString() + "天</span>"))))'
  marks: 'html(if(file.hasTag("待确认"), "<span class=\"pill orange\">要拍板</span> ", "") + if(file.hasTag("待补"), "<span class=\"pill grey\">缺资料</span>", ""))'
summaries:
  几页: 'values.length'
properties:
  file.name:
    displayName: 页
  formula.follow_label:
    displayName: 跟进
  formula.marks:
    displayName: 标记
views:
  - type: table
    name: 现在做到哪
    filters:
      and:
        - 'file.path == "我的知识库.md"'
    order:
      - file.name
      - note.做到哪一步
      - note.下一步
      - note.更新
    columnSize:
      file.name: 200
      note.做到哪一步: 100
      note.更新: 120
      note.下一步: 520
  - type: table
    name: 库里都有什么
    filters:
      and:
        - 'file.inFolder("wiki")'
        - 'file.hasProperty("类型")'
    groupBy:
      property: note.类型
      direction: ASC
    order:
      - file.name
      - note.状态
      - note.更新
    columnSize:
      file.name: 200
      note.状态: 90
      note.更新: 120
    summaries:
      file.name: 几页
  - type: table
    name: 最近更新
    filters:
      and:
        - 'file.inFolder("wiki")'
        - 'file.hasProperty("类型")'
    order:
      - file.name
      - note.类型
      - note.状态
      - file.mtime
    columnSize:
      file.name: 200
      note.类型: 90
      note.状态: 90
      file.mtime: 150
    sort:
      - property: file.mtime
        direction: DESC
    limit: 15
  - type: table
    name: 本周要跟进
    filters:
      and:
        - 'file.inFolder("wiki")'
        - 'formula.follow_days <= 7'
    order:
      - file.name
      - note.类型
      - note.负责人
      - note.下次跟进
      - formula.follow_label
      - note.最要紧的事
    columnSize:
      file.name: 200
      note.类型: 90
      note.负责人: 90
      note.下次跟进: 120
      formula.follow_label: 90
      note.最要紧的事: 410
    sort:
      - property: note.下次跟进
        direction: ASC
  - type: table
    name: 要拍板的和还缺的
    filters:
      and:
        - 'file.inFolder("wiki")'
        - or:
            - 'file.hasTag("待确认")'
            - 'file.hasTag("待补")'
    order:
      - file.name
      - note.类型
      - formula.marks
      - file.mtime
    columnSize:
      file.name: 200
      note.类型: 90
      formula.marks: 150
      file.mtime: 150
    sort:
      - property: file.mtime
        direction: DESC
  - type: table
    name: 还没整理的原件
    filters:
      and:
        - 'file.inFolder("raw")'
        - 'file.basename != "放原始资料"'
        - 'file.backlinks.length == 0'
    order:
      - file.name
      - file.ext
      - file.size
      - file.mtime
    columnSize:
      file.name: 200
      file.ext: 70
      file.size: 90
      file.mtime: 150
```

## 按结构加视图

照下面的样子，在 `views:` 下面加，目录名、项名换成这个库的。加了视图，记得在首页加一节 `![[看板.base#视图名]]`。

按一项分组（比如电商的“活动到哪一步了”、采购的“供应商还用不用”、人事的“候选人到哪一步了”）：

```yaml
  - type: table
    name: 活动到哪一步了
    filters:
      and:
        - 'file.inFolder("wiki/活动")'
    groupBy:
      property: note.做到哪一步
      direction: ASC
    order:
      - file.name
      - note.平台
      - note.开始
      - note.结束
      - note.负责人
    columnSize:
      file.name: 200
      note.平台: 90
      note.开始: 120
      note.结束: 120
      note.负责人: 90
```

只看没办完的（比如生产的“没办完的异常”、采购的“没办完的问题”）：

```yaml
  - type: table
    name: 没办完的异常
    filters:
      and:
        - 'file.inFolder("wiki/异常")'
        - 'note["办完没有"] != "办完了"'
    groupBy:
      property: note.多严重
      direction: ASC
    order:
      - file.name
      - note.日期
      - note.产品
      - note.负责人
    columnSize:
      file.name: 200
      note.日期: 120
      note.产品: 140
      note.负责人: 90
    sort:
      - property: note.日期
        direction: DESC
```

用卡片的样子看（适合商品、岗位这种一眼看全的）：

```yaml
  - type: cards
    name: 所有商品
    filters:
      and:
        - 'file.inFolder("wiki/商品")'
    order:
      - file.name
      - note.平台
      - note.售价
      - note.在不在卖
    columnSize:
      file.name: 200
      note.平台: 90
      note.售价: 90
      note.在不在卖: 90
```

## 常见改法

- **“首页再加一块，按某样分”**：照上面“按一项分组”加一个视图，`groupBy` 的 `property` 换成那一项，视图名起成“客户按地区”这样。
- **“本周要跟进改成两周”**：把 `'formula.follow_days <= 7'` 改成 `<= 14`，视图名改成“两周内要跟进”，首页那一节的视图名一起改。
- **“只看某个负责人的”**：在那个视图的 `filters` 的 `and` 里加一行 `'note["负责人"] == "小林"'`。
- **“最近更新多显示几条”**：把 `limit: 15` 改大。
- **“按我想要的顺序分组”**（比如做到哪一步按先后排）：在那个视图里加一项 `groupOrder`，跟 `groupBy` 对齐（是视图的一项，不放进 `groupBy` 里面），把这一项所有用到的值按顺序列上，最后加一行 `- null`（没填的那组）。漏列的值会被藏起来，所以要列全。这是较新的写法，旧版 Obsidian 不认，不生效就删掉这一项。

  ```yaml
    - type: table
      name: 客户到哪一步了
      groupBy:
        property: note.做到哪一步
        direction: ASC
      groupOrder:
        - 新询价
        - 已报价
        - 打样
        - 谈判
        - 成交
        - 暂停
        - null
  ```
