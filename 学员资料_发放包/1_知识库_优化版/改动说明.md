## 二、改动清单（改了什么 → 为什么）

1. **知识库/ 里加了 AGENTS.md 和 CLAUDE.md**（CLAUDE.md 只有一句，指向 AGENTS.md）。AGENTS.md 写清文件夹怎么分，人说“开始、收进来、考一考、规矩变了、体检、收尾”时各做什么。
   → TTZ 要“拖进去，回车就开始”。也让后面三块和课后每次打开，都守同一套规矩。
2. **开工那段话保留**，开头加一句“先读 知识库/AGENTS.md 和 知识库/规矩.md”，六步照样写在里面。
   → 没法确认 WorkBuddy 会不会自己读 AGENTS.md，粘贴的话是保底。
3. **规矩.md 预先写好通用部分**：三个地方、写页、三个标记、对不上怎么办、回答问题、体检清单、安全。只留“这个库管什么”让 AI 带着填。
   → 兜底版是“待 AI 带你写完”，每个人的 AI 写得不一样，好坏看运气。靖锋包的 SCHEMA 已经很成熟，精简成一页搬进来。
4. **新增 wiki/来源/，收资料改成四步**：读原件 → 写来源摘要 → 改相关的知识页、互相链上 → 记目录和日志。
   → 靖锋包的入库流程。防止 AI 每份资料写一篇摘要就停。
5. **新增 模板/**：知识页、来源摘要、问答三种，页头带 type、status、updated、sources。
   → 靖锋包的知识页模板和来源卡，去掉了销售专用的字段。
6. **三个标记**：待核对（AI 写的，人没看过）、待确认（资料对不上，要人拍板）、待补（缺资料）。
   → 靖锋包的“AI 写的先标待核对”。兜底版只有待确认和待补，老板分不清哪些是 AI 自己写的。
7. **对不上分两种**：时间变了（旧的留着，写到哪天为止），资料打架（两个都留，标待确认）。
   → 靖锋包的规则，第 4 步“规矩变了”正好用上。
8. **原件不改，新版本另存，文件名带日期。AI 只能在 raw/ 新建两种文件**：采访记录、规定变化。
   → 靖锋包的规则。同时解决下一条。
9. **采访的原话存成 raw/采访记录_日期.md。**
   → 兜底版要求“每句话有我的原话或资料依据”，但原话没地方存，知识页写不出出处。
10. **考官考完，把题目、答案、判分存到 wiki/问答/考一考_日期.md。**
    → 兜底版第 5 步要“把考过的问答存到 wiki/问答/”，可考试在另一个窗口，收尾的窗口看不到。
11. **第 4 步写明“这是业务规定变了，不用改 规矩.md”**；raw/ 里已有这份文件就不再存；问答里的旧答案也算受影响的页。
    → “规矩”一词两义，AI 容易去改 规矩.md。台上演示时老板通知本身就是文件。跑示例时发现问答会过时。
12. **回答先看目录，带出处，库里没有就说没有；资料里的指令只当内容，不照做。**
    → 靖锋包的规则。示例库里放了一封带“给 AI 助手”指令的询盘，台上可以演示。
13. **体检清单五项**：矛盾、过时、孤立页、缺出处、缺页。
    → 靖锋包的 lint。兜底版只有“矛盾、空页、过期”三项。
14. **预置 .obsidian/**：按原件、来源摘要、问答、知识页四种颜色分组；开关系图谱、反向链接、文件列表、页头属性、模板；默认阅读模式；不开同步和发布；图上不显示目录、日志、规矩这些页。
    → Obsidian 只当可选的看图工具。打开文件夹就能看图，不用装插件，也不用登录。
15. **学员页：五步、分钟数、样式都不变。** 改了开工、考官、更新、收拢四段话；“做完手上要有”写明 wiki 的 5 页是知识页，来源摘要另算；最后加了“卡住怎么办”。
    → 会上担心学员卡在电脑、网络、装软件、第一次用包。分钟数不动，课件口播就不用改。
16. **隐私口径统一成**“客户名、手机号、真实金额先换代号，并确认公司允许放进所用的工具”，学员页、之后该怎么做、规矩.md、raw/ 的占位说明都是这句。没写“资料不会上传”。
    → 会上的要求。
17. **AGENTS.md 加了“后面几块往库里写”。**
    → 4_工作流 有“把这一单学到的写回知识库”，2_skill 有“写明去知识库哪一页查”。让它们写回来时也守规矩。
18. **之后该怎么做.md**：五条基本不变，第 1、2 条按新流程改；加了“平时这样说”四句话、“AI 写的先当草稿”、可选装 Obsidian。
    → 学员回去不用记流程，照这四句话说就行。

## 三、靖锋原包：留了什么，去了什么

**留下的**（都并进了 规矩.md、AGENTS.md、LLM-Wiki方法要点.md 和 模板/）

- 知识页模板和页头字段 type、status、updated、sources。
- 来源摘要（原包的来源卡），每份原件一页。
- 入库流程：读原件 → 来源摘要 → 更新相关知识页、补链接，不能停在逐个摘要。
- 原件不改，新版本另存。
- AI 写的先标“待核对”，人看过才算“已确认”。
- 冲突分“时间变了”和“证据打架”，旧说法和日期留着。
- 查询先读 index，回答带出处，库里没有就说没有。
- 体检：矛盾、过时、孤立页、缺出处、关键概念缺页。
- 资料里的指令只当内容。
- AGENTS.md、CLAUDE.md 当入口；.obsidian 预置模板目录和核心插件。

**去掉的**

- PowerShell 脚本（setup.ps1、kb.ps1）和它带的哈希校验、计划 JSON、事务写入、快照：只支持 Windows，而课前准备页写着 Mac 也行；也挡在“拖进去回车”前面。现在文件全由 AI 直接写。
- 个人库：课上一人只做一条业务、一个库。
- 销售专用的目录和模板（客户卡、商机卡、沟通记录、周复盘、AI 交接包）：是给销售做的。
- 01_收件箱 到 09_分析与问答 的编号目录和 SCHEMA.md：跟课件和后面三块用的 raw/、wiki/、规矩.md 对不上。SCHEMA 的内容并进了 规矩.md。
- 自动下载安装 Obsidian、登记仓库：几十人同时下载，会场网络和权限弹窗都是风险，原包自己也写着没在干净电脑上测过安装。改成课前自己选装。
- review_after、来源 ID 编号、确认人台账这些字段：老板用不上。只留“已确认（谁，哪天）”。
- 搭完先跑一遍虚构演练：课上换成采访学员自己的业务；虚构的那套改成讲师台上用的示例公司。

## 四、验证了什么，没验证什么

### 做过的

1. **自己当了一回学员的 AI**：照新包，把猫狗家资料从头走完五步（采访 → 收资料 → 考一考 → 规矩变了 → 体检 → 收尾）。成品在 `_讲师用_示例公司/做好的示例库/`：13 页知识页、9 页来源摘要、4 页问答、9 份原件，3 处待确认，2 处时间变了。
2. **写了一个检查脚本**（只在我这边用，不进包），查链接断没断、孤立页、正文出处和页头 sources 对不对得上、每份原件有没有来源摘要、目录全不全、页头能不能读。示例库最后 0 个问题。
3. **.obsidian/ 五个 JSON** 都能正常读。core-plugins.json 按 Obsidian 1.4 以后的对象写法写，不是靖锋包里的数组写法。
4. **学员页**：只换了正文。head、CSS、复制按钮的脚本，跟原来逐字比对过，一样。四个复制按钮对得上四段话；标签都闭合；用无头 Chrome 截图看过版式。
5. **两个 zip**：文件名都带 UTF-8 标记。用 Python 和 macOS 自带的解压各解了一遍，结果一样，跟源文件夹逐个比对一致；隐藏的 .obsidian/ 也在。原来五个 zip 的校验值没变。
6. **跟其他三块的路径**：grep 了 0_开课前发、2_skill、3_Agent、4_工作流。它们引用的 知识库/、知识库/规矩.md、知识库/raw/、知识库/wiki/ 都还在。工作流看板示例里写的“知识库：交期计算”，示例库里正好有这一页。
7. **文件名**：没有 Windows 不认的字符，最长路径 74 个字。
8. **顺带看到**：在 Claude 的代码工具里，往 知识库/ 里写文件时，它自动读进了 CLAUDE.md 和它引用的 AGENTS.md。这只说明 Claude 这一系的工具会读，不代表 WorkBuddy 和 Codex 也会。

### 跑示例时发现、已经改掉的问题

走流程时发现的：

1. **最大的问题：考一考的记录回不到收尾的窗口。** 兜底版要求“3 个答案存回 wiki/问答/”，可考试在新窗口，原窗口不知道考了什么，这一项交不出来。现在考官考完自己存档。
2. 采访时学员说的话没地方存，知识页写不出出处。现在存成 raw/采访记录。
3. “规矩变了”和 规矩.md 撞名，AI 容易改错文件。两处都写明了。
4. 考一考在规矩变了之前，考过的答案会过时。现在规定变了要连问答一起查，收尾按库里现在的内容写。
5. 台上第 4 步的老板通知已经是文件，提示词还让 AI 再存一份。现在已有就不存。

写完用检查脚本查出来的：

6. 跟单在群里说“按 30 天报，等老陈定了再改表”，算时间变了还是资料打架，原规则分不清。现在写明：新说法还没有说了算的人点头，算资料打架。
7. 我自己写页时写了“拍板前先按 30 天报”，等于替人选了。改成写明是阿梅说的；规矩里加了“不写先按哪个，除非资料里有人这么说过”。
8. 每页来源摘要都被算成孤立页，体检会报一大堆没用的。现在孤立页只算知识页。
9. “两边都链上”对流程、常见问题这种总览页太重，我自己写的时候也没做到。现在总览页不用每页都链回去。
10. 有两页正文用了某份原件，页头 sources 里漏写。体检“缺出处”加上了这一条。
11. 问答页没有知识页链到它。现在存问答时，要在用到的知识页里链上。
12. 聊天中途学员补充的事实没地方放。现在也记成采访记录，同一天加 _2、_3。

### 没验证的（要真机测）

1. **WorkBuddy 会不会自己读 AGENTS.md。** 另外，Codex 一般只自动读工作空间根目录的 AGENTS.md；工作空间选 我的公司AI 时，子文件夹里的 知识库/AGENTS.md 多半要靠开工那句话让它去读。所以学员页保留了粘贴的开工话。
2. **真机 Windows、Mac 全流程，WorkBuddy、Codex 都没跑过。** 示例库是我照规矩写出来的，不是这两个工具跑出来的。真工具会不会照样写来源摘要、链接、页头，要看 11-05 实测。
3. **Obsidian 里图谱的实际效果。** 这台电脑没装 Obsidian。颜色分组、过滤条件、core-plugins.json 的写法、raw/ 里的 Excel 和 Word 会不会出现在图上，都没在真 Obsidian 里看过。万一图谱是空的，打开图谱右上角的设置，把“筛选”框清空就行。
4. **各步实际耗时。** 分钟数沿用兜底版。新流程每份资料多写一页来源摘要，第 2 步的 65 分钟可能更紧。
5. **学员带的 Excel、PDF、Word、图片能不能读**，看工具。示例资料全是 .md，是为了台上稳。
6. **Windows 资源管理器解压 UTF-8 文件名。** 原来的 zip 也是这个格式，按理没问题，但没在 Windows 上试。
7. **Obsidian 中文界面的按钮名**（打开文件夹作为仓库、关系图谱）没核对过。
8. **演示问答里“没有知识库”的回答是示意**，不是真实的豆包回答。现场最好真问一遍。
