# 台上口径：AI 采访时这样答

【示例／虚构】你演的是猫狗家的外贸业务员周晓。AI 问的顺序和说法会不一样，意思对上就行。答一两个就可以停，让学员开始。

| AI 可能问 | 照这个答 |
| --- | --- |
| 你的岗位？这次管哪条业务？ | 外贸业务员。只管回海外经销商的询盘，就是第一封回信。 |
| 最常被问的是什么？ | 价格、多久能到、能不能贴 logo、有没有证书、定金怎么付。 |
| 哪些资料最可靠？ | 价格表和交期表。价格表是老陈做的，交期表是阿梅做的。别的都以这两张为准。 |
| 哪些已经过期了？ | 2025 年那份回询盘做法，大部分还能用，海运天数是老的，按交期表。 |
| 拿不准时谁拍板？ | 价格、交期、付款问老陈。证书问阿梅。 |
| 最容易出错的是哪里？ | 交期。新人老从今天算，不从收到定金那天算，还忘了加旺季的 10 天。 |
| 有什么绝对不能答应？ | 不替工厂答应到货日期；不低于最低档；logo 和彩盒不到 1,000 件不做。 |
| 这几封询盘的客户以前下过单吗？ | 都没有，都是第一次来。 |
| 还缺什么资料？ | 说明书、证书原件、客户下单记录都不在手上，先用现有的。 |

可以顺手演一次“不知道”：AI 问一个口径里没有的，就答“这个我说不清，写待补”。
