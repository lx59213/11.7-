# 客服看板

**要用到的项**：问题卡的 `分类`、`产品`、`多常见`、`能直接答吗`、`一句话答法`；工单卡的 `客户`、`日期`、`产品`、`问题`、`办完没有`、`负责人`、`下次跟进`。
目录名或项名改过的，下面照着换；不记工单的，删掉“没办完的工单”和“最近工单”。

## 看板.base

```yaml
filters:
  and:
    - '!file.inFolder("_参考")'
    - '!file.inFolder("模板")'
    - 'note["示例"] != true'
formulas:
  follow_days: 'if(note["下次跟进"], (date(note["下次跟进"]) - today()).days, 999)'
  follow_label: 'if(formula.follow_days < 0, html("<span class=\"pill red\">过了" + formula.follow_days.abs().toString() + "天</span>"), if(formula.follow_days == 0, html("<span class=\"pill red\">今天</span>"), if(formula.follow_days == 1, html("<span class=\"pill orange\">明天</span>"), html("<span class=\"pill grey\">还有" + formula.follow_days.toString() + "天</span>"))))'
  marks: 'html(if(file.hasTag("待确认"), "<span class=\"pill orange\">要拍板</span> ", "") + if(file.hasTag("待补"), "<span class=\"pill grey\">缺资料</span>", ""))'
summaries:
  几页: 'values.length'
properties:
  file.name:
    displayName: 页
  formula.follow_label:
    displayName: 回访
  formula.marks:
    displayName: 标记
views:
  - type: table
    name: 现在做到哪
    filters:
      and:
        - 'file.path == "我的知识库.md"'
    order:
      - file.name
      - note.做到哪一步
      - note.下一步
      - note.更新
    columnSize:
      file.name: 200
      note.做到哪一步: 100
      note.更新: 120
      note.下一步: 520
  - type: table
    name: 常见问题按分类
    filters:
      and:
        - 'file.inFolder("wiki/问题")'
    groupBy:
      property: note.分类
      direction: ASC
    order:
      - file.name
      - note.产品
      - note.多常见
      - note.能直接答吗
      - note.一句话答法
    columnSize:
      file.name: 200
      note.产品: 140
      note.多常见: 90
      note.能直接答吗: 90
      note.一句话答法: 480
  - type: table
    name: 没办完的工单
    filters:
      and:
        - 'file.inFolder("wiki/工单")'
        - 'note["办完没有"] != "办完了"'
    order:
      - file.name
      - note.日期
      - note.产品
      - note.办完没有
      - note.负责人
      - formula.follow_label
    columnSize:
      file.name: 200
      note.日期: 120
      note.产品: 140
      note.办完没有: 90
      note.负责人: 90
      formula.follow_label: 90
    sort:
      - property: note.日期
        direction: ASC
  - type: table
    name: 最近工单
    filters:
      and:
        - 'file.inFolder("wiki/工单")'
    order:
      - note.日期
      - file.name
      - note.产品
      - note.问题
      - note.办完没有
    columnSize:
      note.日期: 120
      file.name: 200
      note.产品: 140
      note.办完没有: 90
      note.问题: 450
    sort:
      - property: note.日期
        direction: DESC
    limit: 10
  - type: table
    name: 要请示的问题
    filters:
      and:
        - 'file.inFolder("wiki/问题")'
        - 'note["能直接答吗"] == "要请示"'
    order:
      - file.name
      - note.分类
      - note.产品
      - note.一句话答法
    columnSize:
      file.name: 200
      note.分类: 90
      note.产品: 140
      note.一句话答法: 520
  - type: table
    name: 要拍板的和还缺的
    filters:
      and:
        - 'file.inFolder("wiki")'
        - or:
            - 'file.hasTag("待确认")'
            - 'file.hasTag("待补")'
    order:
      - file.name
      - note.类型
      - formula.marks
      - file.mtime
    columnSize:
      file.name: 200
      note.类型: 90
      formula.marks: 150
      file.mtime: 150
    sort:
      - property: file.mtime
        direction: DESC
  - type: table
    name: 还没整理的原件
    filters:
      and:
        - 'file.inFolder("raw")'
        - 'file.basename != "放原始资料"'
        - 'file.backlinks.length == 0'
    order:
      - file.name
      - file.ext
      - file.size
      - file.mtime
    columnSize:
      file.name: 200
      file.ext: 70
      file.size: 90
      file.mtime: 150
  - type: table
    name: 库里都有什么
    filters:
      and:
        - 'file.inFolder("wiki")'
        - 'file.hasProperty("类型")'
    groupBy:
      property: note.类型
      direction: ASC
    order:
      - file.name
      - note.状态
      - note.更新
    columnSize:
      file.name: 200
      note.状态: 90
      note.更新: 120
    summaries:
      file.name: 几页
```

## 常见改法

- **“按产品分”**：照 `02_销售看板.md` 的“按地区分”那一段，目录换成 `wiki/问题`，`property` 换成 `note.产品`，视图名叫“问题按产品”。
- **“只看天天有的问题”**：在“常见问题按分类”的 `filters` 的 `and` 里加 `'note["多常见"] == "天天有"'`，视图名和首页一起改。
- **“问题一个一个排开看”**：加一个 `type: cards` 的视图，写法见 `01_通用看板.md`。
