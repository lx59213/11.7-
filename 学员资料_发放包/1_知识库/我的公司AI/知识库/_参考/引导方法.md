# 引导方法：① 定怎么问

一共四问，都给选项，他回字母。每问最后一个选项是“说不清，你来定”（第 1 问是“其他”）。问法照 README.md“问题一律这样问”。选项从 `结构示例/09_每个岗位的选项.md` 里他那个岗位拿。

## 四个问题

**第 1 问：岗位。**

```
第 1 问（一共 4 个）：你的岗位最接近哪个？回一个字母。
A 销售、业务、外贸
B 客服、售后
C 电商运营
D 采购、供应链、仓储、跟单
E 生产、品质
F 人事、招聘、行政
G 老板、管理
H 其他（用一句话说说你干什么）
```

没有建议（他是谁只有他知道）。答完读对应那套示例（A=01_销售 …… H=08_通用）的全文。

**第 2 问：这个库先管哪一条业务。** 单选。建议选最窄的那条——先管一条，顺了再扩。

**第 3 问：最常查的几件事。** 可以多选，回三到五个字母。建议挑那个岗位最常见的四五个。

**第 4 问：库怎么分。** 直接给推荐的那种分法的样子（下面“分法这样给”），后面的选项里带上另外两种分法各一句话，他看着样子选。推荐 A；第 3 问他选的多是“规定怎么定”这类，推荐 C，选项里换成 A、B。

“这个库给谁用”不问，写“先给自己用，以后给新同事看”。“拿不准时谁说了算”不问，有对不上的收尾时再请他定。首页放什么不问，照那套示例。

## 分法这样给

开头说“你的库打算这样分”。不画目录树，不写 wiki/、模板/ 这些文件夹名。“每页记这些事”里的项名就是以后页头的项名，一字不差；项从那套示例来，第 3 问他选的事要有地方记（选了“到哪个港”，每笔生意就记“到哪个港”）。

```
你的库打算这样分（照“销售”的 A 分法，按你选的改了）：

分成 5 块：
- 客户：每个客户记一页
- 商机：每笔生意记一页
- 沟通：每次来回的邮件记一笔（电话、微信也算）
- 规定：报价、交期、付款这些规定，一条一页
- 产品：一个产品一页
另外 3 块是固定的，不用你管：每份资料的要点、问过的问题、归不了类的。

每页记这些事：
- 每个客户：地区、新老、做到哪一步、负责人、下次跟进、最要紧的事
- 每笔生意：客户、产品、数量、到哪个港、做到哪一步、下次跟进、下一步
- 每次来回：客户、商机、日期、方式、说了什么
- 做到哪一步只填：新询盘、已报价、打样、谈判、成交、暂停

可以吗？
A 就这样
B 换成 B 分法：〖产品、规定、客户三块〗
C 换成 C 分法：〖规定、流程、常见问题三块〗
D 改一处（告诉我改什么，比如“每个客户再多记一样：国家”）
```

他选 B、C、D，改了再给一遍，还是这样问。选 A，回 README.md 接着做。
