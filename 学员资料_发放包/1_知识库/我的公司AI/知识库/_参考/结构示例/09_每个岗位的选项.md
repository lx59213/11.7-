# 每个岗位的选项

① 第 1 问选了岗位，后面几问的选项从这里拿；② 第 1 问“有哪些资料”也从这里拿。用他说过的话改选项里的词。每个列表最后都加一个“说不清／你来定”。

**三种分法**（① 第 4 问）每个岗位都给这三种：
- **A 按人和事分**：那套示例原样，每个客户、每笔生意都单独一页。天天跟人打交道、要跟进的选这个。建议默认选 A。
- **B 按东西分**：以产品、物料这类“东西”为主，每样一页记全；人和事只留一块，记得简单。手上主要是产品资料、价格表的选这个。
- **C 只记规矩和答法**：只有规定、流程、常见问题三块，不给每个人、每件事单独一页。资料多是制度文件、只想先查规矩的选这个；最快搭好。

给的时候每种一句话说清分成哪几块，像下面各岗位写的那样。选 B、C 的，项从 A 那套示例里挑，同名的照用。

## A 销售、业务、外贸（01_销售）

- 管哪条业务：A 回新客户的询盘　B 跟老客户、催回款　C 报价和合同　D 整个销售
- 最常查（可多选）：A 价格怎么报　B 多久能交货　C 定金、付款怎么收　D 能不能贴牌、换包装　E 有没有证书　F 某个客户上次聊到哪了　G 起订量　H 运费、到哪个港
- 资料一般有：A 报价单、价格表　B 合同、订单、形式发票　C 客户邮件、询盘　D 聊天记录、截图　E 产品资料、证书　F 交期表、生产排期　G 销售台账（Excel）
- 三种分法：
  - A 客户、商机、沟通、规定、产品五块：每个客户一页，每笔生意一页，每次来回一笔
  - B 产品、规定、客户三块：每个产品一页记全价格、交期、证书、能不能贴牌；客户只记基本情况
  - C 规定、流程、常见问题三块：报价、交期、付款怎么定，回客户常用的答法

## B 客服、售后（02_客服售后）

- 管哪条业务：A 回答客户咨询　B 投诉和退换货　C 维修、技术支持　D 整个售后
- 最常查：A 发货多久到　B 怎么退换　C 坏了怎么修　D 产品怎么用　E 能不能便宜点、送赠品　F 赔多少　G 什么情况要升级给主管
- 资料一般有：A 客服话术、常见问题　B 退换货、赔偿规定　C 产品说明书　D 工单、投诉记录（Excel）　E 聊天记录、截图　F 培训资料
- 三种分法：
  - A 问题、工单、口径、产品四块：每类问题一页写标准答法，每张工单一页
  - B 产品、口径两块：每个产品一页，写常见问题和答法、保修
  - C 口径、流程、常见问题三块：不记工单，只记怎么答、怎么办

## C 电商运营（03_电商运营）

- 管哪条业务：A 商品上架和定价　B 活动报名和执行　C 数据复盘　D 整个店铺
- 最常查：A 某个商品现在什么价　B 库存还有多少　C 活动怎么报名　D 上次活动卖了多少　E 平台规则改了什么　F 售后话术
- 资料一般有：A 商品表、价格表　B 活动方案、报名表　C 周报、月报、复盘　D 平台规则通知　E 售后话术　F 数据导出表
- 三种分法：
  - A 商品、活动、复盘、规则四块：每个商品一页，每场活动一页，每次复盘一页
  - B 商品、规则两块：每个商品一页记全价格、库存、卖点、活动记录
  - C 规则、流程、常见问题三块：平台规则、发货、售后怎么办

## D 采购、供应链、仓储、跟单（04_采购供应链）

- 管哪条业务：A 找供应商、比价　B 下单和跟单　C 来料和质量问题　D 整个采购
- 最常查：A 某个物料谁家供　B 什么价　C 几天能到货　D 这家供应商靠不靠谱　E 付款要谁批　F 出过什么问题
- 资料一般有：A 供应商名录　B 报价单、比价表　C 采购合同、订单　D 物料清单　E 来料检验、问题记录　F 审批、付款规定
- 三种分法：
  - A 供应商、物料、问题、规定四块：每家供应商一页，每个物料一页，每次出的问题一页
  - B 物料、供应商两块：每个物料一页记全谁家供、价格、交期
  - C 规定、流程、常见问题三块：比价、下单、验收、付款怎么办

## E 生产、品质（05_生产品质）

- 管哪条业务：A 车间生产　B 来料和成品检验　C 设备保养　D 整个生产
- 最常查：A 某个产品的工艺参数　B 检验标准　C 设备什么时候保养　D 上次出这个毛病怎么处理的　E 哪条规定改了
- 资料一般有：A 作业指导书　B 检验标准　C 设备台账、保养记录　D 异常、客诉报告　E 生产日报　F 安全规定
- 三种分法：
  - A 设备、异常、作业规定、产品四块：每台设备一页，每次异常一页
  - B 产品、作业规定两块：每个产品一页记全工艺路线、参数、检验标准
  - C 作业规定、流程、常见问题三块：只记规矩和处理办法

## F 人事、招聘、行政（06_人事招聘）

- 管哪条业务：A 招聘　B 考勤和假期　C 薪酬福利　D 入职离职　E 整个人事
- 最常查：A 年假怎么算　B 加班怎么算　C 入职要交什么　D 某个岗位招到哪一步　E 离职怎么办手续　F 报销怎么走
- 资料一般有：A 员工手册、制度　B 岗位说明　C 招聘需求、简历（只用代号）　D 考勤、假期规定　E 表格模板　F 通知公告
- 三种分法：
  - A 岗位、候选人、制度三块：每个岗位一页，每个候选人一页（只写代号）
  - B 岗位、制度两块：每个岗位一页记全要求和招聘进度，不记候选人
  - C 制度、流程、常见问题三块：最常被问的那些怎么答

## G 老板、管理（07_老板管理）

- 管哪条业务：A 盯重点项目　B 管大客户　C 管团队和制度　D 看经营数字　E 全公司
- 最常查：A 那件事做到哪了　B 这个月数字怎么样　C 大客户有没有问题　D 哪条规矩没人照做　E 谁在等我拍板　F 某个部门最近怎么样
- 资料一般有：A 周报、月报　B 会议纪要　C 经营报表（Excel）　D 公司制度　E 大客户资料、合同　F 项目方案
- 三种分法：
  - A 重点事、大客户、团队、制度、经营五块：每件在推的事一页，每家大客户一页
  - B 重点事、制度两块：每件在推的事一页，制度一条一页
  - C 制度、流程、常见问题三块：先把公司的规矩理清楚

## H 其他（08_通用）

- 管哪条业务：从他第 1 问说的那句话里编三个，再加“D 整个这一摊”
- 最常查：A 某件事怎么办　B 找谁批　C 要交什么材料　D 多久能办完　E 某个说法是什么意思
- 资料一般有：A 制度、规定　B 流程说明　C 表格、台账　D 会议纪要　E 通知、邮件　F 聊天记录、截图
- 三种分法：
  - A 规定、流程、事项、名词四块：每件在办的事一页
  - B 事项、规定两块：每件在办的事一页记全
  - C 规定、流程、常见问题三块
